Désinstaller une application ou le site web dans Odoo 20

Une application installée pour essai, un site web qui ne sert plus : Odoo 20 ne propose pas de bouton « Supprimer » pour une application, mais une désinstallation. Elle se fait en quelques clics, à condition de lire la fenêtre qui s'affiche avant : elle annonce tout ce qui part avec l'application.

~5 minutes de lecture · niveau débutant · série Astuces Odoo 20

Édition : Community. Écrit et vérifié sur Odoo 20.0 Community, octobre 2026, sur une copie de la base de démonstration où Site Web, eCommerce, eLearning, Événements et Recrutement étaient installés. Le module Site Web existe aussi dans l'édition Enterprise.

La réponse en bref

  1. Ouvrez Applications, cherchez l'application, puis menu ⋮ de sa carte › Désinstaller…
  2. Lisez la fenêtre : elle liste les applications et modules emportés avec elle.
  3. Cliquez sur Désinstaller : les données propres à ces modules sont effacées, les autres applications restent intactes.
  4. Pour retirer un seul site parmi plusieurs, supprimez-le dans Site Web › Configuration › Sites web au lieu de désinstaller.

1. Trouver le bouton Désinstaller

La désinstallation est réservée aux administrateurs de la base. Elle se lance depuis l'écran des applications, celui qui sert à les activer.

  1. Ouvrez le menu Applications.
  2. Tapez le nom de l'application dans la barre de recherche, par exemple Site Web, puis validez.
  3. Survolez la carte et cliquez sur les trois points verticaux ⋮ en haut à droite : le menu propose Info sur le module, En savoir plus, Mettre à niveau et Désinstaller…

Le choix Désinstaller… ne désinstalle rien encore : il ouvre une fenêtre de vérification. Les modules du socle d'Odoo (base, web) refusent toute désinstallation.

2. Lire la fenêtre avant de confirmer

La fenêtre « Désinstaller le module » commence par un avertissement : « La désinstallation de modules peut être risquée. Nous vous recommandons d'abord de l'essayer dans un environnement de test. » Suit la liste de ce qui sera supprimé.

Le point clé est l'onglet Apps. Toute application qui a besoin du module retiré part avec lui. Sur la base de démonstration, désinstaller Site Web emporte aussi eCommerce, eLearning, l'application Événements du site (la publication et la vente de billets en ligne) et Online Jobs (les offres d'emploi publiées). L'onglet Modules détaille les 31 modules techniques concernés : formulaire de contact, paiement en ligne, tracker de liens du site, etc.

L'onglet Modèles indique les types de documents qui disparaîtront, avec leur nombre d'enregistrements :

Cette liste ne montre que les documents dotés d'un fil de discussion. Les pages du site, ses menus, les visiteurs suivis ou les catégories de la boutique n'y figurent pas, et sont pourtant supprimés eux aussi (voir la section suivante). Cliquez sur Ignorer pour renoncer, ou sur Désinstaller pour lancer l'opération. La page se recharge une fois la désinstallation terminée.

3. Ce qui disparaît, ce qui reste

Odoo efface tout ce que les modules désinstallés avaient apporté : leurs menus, leurs tables de données, les champs qu'ils avaient ajoutés aux autres documents et les enregistrements qu'ils avaient créés eux-mêmes. Les applications qui ne dépendent pas du site continuent de fonctionner. Relevé sur la base de démonstration :

4. Supprimer un seul site, sans désinstaller

Avec plusieurs sites web dans la même base, retirer l'un d'eux ne demande pas de désinstallation. La liste des sites n'apparaît qu'en mode développeur.

  1. Activez le mode développeur, puis ouvrez Site Web › Configuration › Sites web.
  2. Cochez la ligne du site à retirer, puis Actions › Supprimer.
  3. Confirmez dans la fenêtre « Au revoir, l'enregistrement ! » par Supprimer.

Le site par défaut ne se supprime pas ; Odoo répond : « Vous ne pouvez pas supprimer le site web My Website par défaut. Veuillez plutôt changer ses paramètres ». Pour ne plus avoir de site du tout, la désinstallation décrite plus haut reste la seule voie.

Point de vigilance : une désinstallation ne se rattrape pas

Les tables des modules retirés sont supprimées de la base. Réactiver l'application ensuite ne rend pas les pages, les cours ni les catégories créés auparavant : les tables qui les contenaient n'existent plus. Avant de désinstaller sur une base réelle, faites une sauvegarde, puis essayez l'opération sur une copie de la base, comme le recommande la fenêtre.

À retenir

  • Une application se retire par Applications › ⋮ › Désinstaller…, pas par un bouton Supprimer.
  • L'onglet Apps de la fenêtre montre les applications emportées : Site Web en entraîne quatre autres.
  • Les données propres aux modules retirés sont effacées ; les autres applications gardent les leurs.
  • Un site parmi plusieurs se supprime dans Site Web › Configuration › Sites web, en mode développeur.
