Signature e-mail des utilisateurs dans Odoo 20

Chaque utilisateur d'Odoo 20 possède sa propre signature e-mail, mise en forme et illustrée d'un logo si besoin. Où la régler, comment l'administrateur la règle pour un collègue, et dans quels courriels elle apparaît vraiment.

~5 minutes de lecture · niveau débutant · série Astuces Odoo 20

Édition : Community. Écrit et vérifié sur Odoo 20.0 Community, octobre 2026, sur la base de démonstration (société My Company (San Francisco), applications Ventes et Discussion installées). La signature fait partie du socle d'Odoo ; elle existe aussi dans l'édition Enterprise. Aucun courriel n'a quitté la base de démonstration pendant les essais.

À la création d'un utilisateur, Odoo 20 lui donne une signature réduite à son nom. Elle suit pourtant chaque message envoyé depuis un dossier : la compléter (fonction, téléphone, logo) prend deux minutes et se fait sans droit particulier.

La réponse en bref

  1. Cliquez sur votre avatar en haut à droite, puis sur Mes préférences.
  2. Dans l'onglet Préférences, remplissez le champ Signature e-mail ; sélectionnez du texte pour le mettre en forme, tapez / pour insérer une image.
  3. Cliquez sur Mettre à jour les préférences.
  4. Pour un collègue, l'administrateur passe par Paramètres › Utilisateurs & Sociétés › Utilisateurs, même onglet, même champ.

1. Régler sa propre signature

Le menu de l'avatar, en haut à droite de l'écran, propose Mes préférences. La fenêtre Changer mes préférences s'ouvre sur l'onglet Préférences, où le champ Signature e-mail contient pour l'instant votre seul nom.

Le champ est un petit éditeur de texte. Saisissez les lignes souhaitées ; pour revenir à la ligne sans créer de paragraphe, utilisez Maj + Entrée. Sélectionnez ensuite un mot : une barre apparaît avec le style (Normal), la taille, le gras, l'italique, le souligné, la couleur et le lien. L'exemple met le nom en gras.

Pour ajouter un logo, placez le curseur sur une nouvelle ligne, tapez / et choisissez Média (« Insérer une image ou une icône »). La fenêtre Sélectionner un média propose Télécharger une image pour envoyer un fichier depuis l'ordinateur, ou Ajouter une URL. La capture utilise le logo de la société de démonstration, « Your logo ».

Terminez par Mettre à jour les préférences. Le même chemin vaut pour tout utilisateur interne : chacun règle sa signature lui-même, sans passer par l'administrateur.

L'image n'est pas copiée dans chaque courriel : Odoo la conserve dans la base et le message contient un lien vers elle, avec un jeton d'accès. Au moment de l'envoi, ce lien est complété par l'adresse de la base (paramètre système web.base.url). Le destinataire ne voit donc le logo que si cette adresse est joignable depuis Internet ; sur une base installée en local, il ne s'affichera pas chez lui.

2. Régler la signature d'un collègue (administrateur)

Pour harmoniser les signatures d'une équipe, l'administrateur ouvre Paramètres › Utilisateurs & Sociétés › Utilisateurs, puis la fiche de l'utilisateur. L'onglet Préférences, à côté de Droits d'accès, contient le même champ Signature e-mail, avec la même barre de mise en forme. Il saisit la signature, puis enregistre la fiche.

Sur la démonstration, la fiche de Marc Demo reçoit ainsi « Marc Demo / Commercial, My Company (San Francisco) / mark.brown23@example.com ». L'utilisateur peut ensuite la retoucher depuis ses propres préférences.

3. Où la signature apparaît

Les essais portent sur le devis S00001 d'Acme Corporation, dont le vendeur est Marc Demo, ouvert par Mitchell Admin. Trois façons d'écrire au client donnent trois comportements.

Message rapide du chatter

Le bouton Envoyer message du chatter ouvre une zone de saisie simple. Le message publié dans le fil n'affiche que le texte saisi ; la signature est ajoutée au courriel envoyé aux abonnés, sous la ligne « -- ». Pour vérifier ce qui part réellement, activez le mode développeur et ouvrez Paramètres › Technique › E-mail › E-mails : l'onglet Corps montre le courriel tel qu'il est construit.

Sur la base de démonstration, aucun serveur de courriel sortant n'est configuré : ces courriels restent dans la liste avec l'état Échec de l'envoi, ce qui permet de les relire sans rien envoyer.

Éditeur complet

L'icône Ouvrir l'éditeur complet, dans la zone de saisie, ouvre la fenêtre Rédiger un e-mail. Cette fois, la signature est déjà écrite dans le corps, sous « -- » : elle se relit et se modifie pour ce seul message, sans changer les préférences. Odoo ne l'ajoute pas une seconde fois à l'envoi.

Envoi par un modèle de courriel

Le bouton Envoyer du devis ouvre la fenêtre Envoyer, préremplie par le modèle de courriel des devis, avec le PDF en pièce jointe. La signature affichée est celle de Marc Demo, le vendeur du devis, alors que c'est Mitchell Admin qui envoie.

Avec un modèle, c'est le modèle qui décide de la signature

Odoo 20 n'offre pas de case « ajouter ma signature » dans la fenêtre d'envoi. Sans modèle, il ajoute la signature de l'auteur ; avec un modèle, il n'ajoute rien et laisse le modèle écrire la sienne. Les modèles fournis pour les devis et l'envoi des factures insèrent la signature du Vendeur du document. Pour qu'un devis parte avec une autre signature, changez le vendeur du devis, ou modifiez la signature directement dans la fenêtre Envoyer avant de cliquer : la retouche ne vaut que pour ce courriel.

À retenir

  • Chaque utilisateur règle sa signature dans Mes préférences › Préférences › Signature e-mail ; l'administrateur, dans la fiche de l'utilisateur.
  • Sélectionner du texte affiche la barre de mise en forme ; / puis Média insère un logo, servi depuis la base.
  • Message rapide du chatter : signature ajoutée au courriel sous « -- » ; éditeur complet : signature visible et modifiable dans le corps.
  • Envoi par un modèle (devis, facture) : la signature est celle que le modèle insère, souvent celle du vendeur.
