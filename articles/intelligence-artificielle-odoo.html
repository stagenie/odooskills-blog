L'IA dans Odoo 20 : agents, questions et rédaction

Des agents configurables, une question posée en français sur les données de la base, un texte rédigé dans un champ de la fiche : ce qu'apporte l'application IA de l'édition Enterprise d'Odoo 20.

~9 minutes de lecture · niveau débutant

Édition : Enterprise. Écrit et vérifié sur Odoo 20.0 Enterprise (base hébergée sur odoo.com), octobre 2026.

Retrouver les affaires les plus proches de la signature demande d'ouvrir le pipeline, de filtrer, de trier. Rédiger la note d'une opportunité demande de relire la fiche, ses montants, ses activités. Deux tâches courantes que l'intelligence artificielle d'Odoo 20 prend en charge depuis l'écran où se trouve l'utilisateur.

Cet article installe l'application IA sur une base de démonstration Odoo 20 Enterprise, ouvre ses agents (instructions, compétences, sources), pose une question à l'agent sur les opportunités du CRM, puis fait rédiger la description d'une opportunité par le bouton IA d'un champ de texte. Les réponses reproduites sont celles obtenues le jour de l'essai ; une IA ne répond pas deux fois de la même façon.

Objectifs

À la fin de cet article, vous saurez :

  • installer l'application IA et retrouver ses menus ;
  • lire la fiche d'un agent : instructions, compétences, sources et déclencheurs ;
  • poser une question sur les données de la base et suivre les étapes de l'agent ;
  • faire rédiger un texte dans un champ d'une fiche et le reprendre ;
  • repérer, dans la liste des prompts par défaut, où l'IA apparaît dans les applications.

De l'agent à la réponse dans l'application

Toute question posée à l'IA d'Odoo passe par un agent. L'agent réunit des instructions (son rôle), des compétences (ce qu'il a le droit de faire dans la base) et, éventuellement, des sources (des documents de référence). La question part d'un point d'entrée, l'icône de la barre du haut ou un bouton IA dans un champ ; la réponse revient dans une fenêtre de discussion, et l'utilisateur décide de ce qu'il en garde.

Le haut du schéma correspond aux étapes 2 à 4 (la fiche de l'agent) ; les deux points d'entrée sont essayés aux étapes 5 et 6. La case foncée est l'agent Odoo AI, celui qui a répondu aux deux essais de cet article.

1. Installer l'application IA

Dans l'écran Applications, l'application porte le nom technique ai_agentic ; sa fiche la résume ainsi : « A powerful suite of AI tools and agents integrated directly into your Odoo environment ». Sur la base de démonstration, le module de base de l'IA et ses liaisons avec les applications (CRM, Ventes, Assistance, Connaissances…) étaient déjà installés ; l'application a ajouté six modules, dont les règles d'automatisation (base_automation) et des liaisons avec Documents et Connaissances. Aucune fenêtre d'abonnement ou de changement de plan ne s'est affichée.

Sur odoo.com, la page des tarifs (relevée le 15 octobre 2026) range l'IA agentique dans le plan Personnalisé, avec Studio et le multi-sociétés.

L'application IA compte deux menus : Agents et Configuration (Compétences, Outils, Prompts par défaut). La vue Agents présente une carte par agent, avec sa description et ses compétences.

Huit agents sont livrés, chacun pour un usage : Odoo AI, l'assistant généraliste (« I'm your Odoo sidekick for most day-to-day tasks. ») ; Website Builder pour les pages du site ; deux agents de discussion en direct ; Marketing Campaign Builder pour les campagnes ; Auditor et Audit Reviewer pour la révision comptable ; Odoo Compliance Assistant, un exemple d'agent appuyé sur un document. Leurs descriptions sont affichées en anglais.

2. Les instructions de l'agent

Un clic sur la carte Odoo AI ouvre sa fiche. Elle compte quatre onglets : Instructions, Compétences, Sources et Déclencheurs. Le premier contient le texte qui fixe le rôle et le comportement de l'agent : réponses concises, question de précision seulement si l'information manque, réponse tirée des éléments disponibles, explication brève quand une demande ne peut pas aboutir.

Ces instructions sont un texte libre, rédigé ici en anglais. Le bouton Nouveau de la vue Agents crée un agent avec ses propres instructions ; cet article s'en tient aux agents livrés.

3. Les compétences : ce que l'agent peut faire

L'onglet Compétences définit ce que l'agent a le droit de faire dans la base. Il se lit en trois blocs :

  • Outils : trois cases, Generate Image et Web Search (cochées pour Odoo AI), Self Update (décochée), et le champ Allowed Agents ;
  • Compétences : sept pour Odoo AI, dont Search Database (consulter les enregistrements), Update Records et Create Records (les modifier, en créer), Shape View (ouvrir la vue adaptée à une recherche), deux compétences comptables et Build Automation ;
  • enfin, une rubrique dont l'aide dit « Autoriser cet agent à demander de l'aide à d'autres agents » : Odoo AI peut faire appel à l'agent Auditor.

Le menu IA › Configuration › Compétences liste les 21 compétences disponibles sur la base, avec leur description ; Outils, avec son filtre par défaut, liste les 69 actions qu'elles mettent en œuvre. Le Live Chat AI Agent, par exemple, n'a que Search Database et Create Lead (Livechat) : il consulte la base et enregistre une piste, rien d'autre.

4. Les sources : répondre à partir d'un document

L'agent Odoo Compliance Assistant montre l'usage des sources. Ses instructions lui demandent de citer le numéro de section du document et de dire clairement quand la réponse ne s'y trouve pas. Son onglet Sources contient un seul document, Odoo Enterprise Agreement, avec l'étiquette indexed : le document a été préparé pour que l'agent y retrouve les passages utiles.

La case Restreindre aux sources est cochée ; l'aide du champ précise que l'agent ne répond alors qu'à partir des sources fournies. Le bouton Ajouter ouvre la fenêtre « Ajouter des sources », qui propose quatre provenances : Uploader un fichier, Ajouter un lien, Ajouter depuis Documents et Ajouter depuis Connaissances. Aucune source n'a été ajoutée pour cet article.

Le dernier onglet, Déclencheurs, est vide pour tous les agents de la démonstration. Son texte d'aide : « Ajoutez des déclencheurs pour permettre à votre agent de s'exécuter automatiquement selon un planning ou lorsque des événements clés se produisent. » Ces déclencheurs sont des règles d'automatisation, d'où l'installation de base_automation avec l'application.

5. Poser une question sur les données

L'icône Demander à l'IA, dans la barre du haut, est présente dans toutes les applications. Elle ouvre une fenêtre de discussion avec l'agent Odoo AI, qui propose trois questions toutes prêtes ; elles changent d'une ouverture à l'autre (« What's my agenda for today? », « Pivot of products with less than 5 in stock »…). Quand une conversation précédente existe, un bandeau l'indique : « Nouveau chat démarré. Reprendre le chat précédent ».

La question posée, en français : « Quelles sont les opportunités les plus avancées dans le CRM ? ». Pendant la recherche, la fenêtre affiche ce que fait l'agent (« Vérification des champs des étapes », « Consultation des étapes du pipeline »…). La réponse terminée, la ligne Étapes effectuées se déplie pour relire le cheminement :

L'agent a activé la compétence Search Database vue à l'étape 3, lu les champs des opportunités et des étapes, cherché les étapes du pipeline, les opportunités, puis la devise de la société pour présenter les montants. Il n'a rien modifié : la question ne demandait qu'une lecture.

La réponse classe les opportunités en deux groupes : celles de l'étape Proposition, triées par probabilité, et celles de l'étape Gagné.

Les chiffres ont été recoupés avec le CRM de la base de démonstration : les six opportunités de l'étape Proposition, leurs montants, probabilités, vendeurs et dates de clôture prévues correspondent, tout comme les trois opportunités gagnées. Le tiret signale une opportunité sans client ou sans date. La conversation est conservée dans l'application Discussion, rubrique IA, sous un titre donné automatiquement (ici « Innovations CRM avancées »).

Pour poser vos propres questions sur une base à soi, l'essai en ligne de l'édition Enterprise part de la page d'accueil d'Odoo ; l'application IA s'installe ensuite depuis l'écran Applications.

6. Faire rédiger un texte dans un champ

L'IA est aussi présente dans les champs de texte des fiches. Ouvrez l'opportunité Need 20 Desks (CRM, étape Proposition) et cliquez dans l'onglet Notes : à droite de « Tapez "/" pour les commandes », une barre d'icônes apparaît, dont l'icône IA, intitulée « Générer ou transformer du contenu grâce à l'IA ».

Le clic ouvre une fenêtre de discussion avec Odoo AI, rattachée à l'opportunité : son titre est d'abord le nom de la fiche. La demande : « Rédige une courte description de cette opportunité, en trois phrases, pour l'équipe commerciale. »

Le texte reprend les données de la fiche : la ville (Lima), le revenu attendu, la probabilité, la date de clôture prévue, l'étiquette Consulting (« conseil ») et l'activité en retard « Confirm order by email » de Mitchell Admin. Sous la réponse, deux boutons : Utiliser ceci et Copier le texte. Utiliser ceci place le texte dans le champ Notes :

Le texte est inséré, pas enregistré : la fiche est en cours de modification, comme après une saisie à la main. Pour cet article, la modification a été ignorée ; la description de l'opportunité de démonstration est restée vide.

7. Où l'IA apparaît dans les applications

Le menu IA › Configuration › Prompts par défaut donne la carte des points d'entrée. Chaque ligne associe un endroit de l'interface (colonne Nom), une action et l'agent qui répond. Le bouton du champ Notes de l'étape 6 correspond à la ligne Record HTML Fields, « Écrire dans un champ HTML » ; l'icône de la barre du haut, à Ask AI, « Demander de l'aide à l'IA ».

La liste compte 22 lignes. Elle montre que l'IA intervient aussi dans la rédaction des e-mails, la réécriture d'un texte sélectionné, les pièces jointes, la génération d'images de produits, les articles Connaissances, le référencement du site, les tickets d'assistance, les feuilles de temps et les posts des réseaux sociaux. Ces points d'entrée n'ont pas été essayés un par un pour cet article ; seuls ceux des étapes 5 et 6 l'ont été.

Ce que décrit la documentation d'Odoo : les champs IA

Les champs remplis par l'IA n'ont pas pu être essayés sur la base de démonstration ; selon la documentation d'Odoo 20, page AI fields, un champ IA est un champ de formulaire dont la valeur est produite par l'IA à partir d'un prompt, qui peut citer d'autres champs de la fiche. Rien de cette section n'a été vu à l'écran.

  • Sans Studio, la documentation passe par les champs de propriétés : icône des actions de la fiche, Edit Properties, puis la case AI, le type du champ et le prompt. Ces champs ne s'ajoutent qu'aux vues formulaire.
  • Avec Studio, l'option AI Field se glisse sur le formulaire ; la documentation liste les types possibles (texte, nombre, montant, date, case à cocher, relation, étiquettes…).
  • L'icône IA placée à côté du champ calcule ou recalcule sa valeur. Une action planifiée quotidienne, active par défaut, remplit les champs IA de type texte et les propriétés restés vides.

La page générale AI de la documentation ajoute que la palette de commandes (Ctrl+K) donne aussi accès à la discussion avec l'IA, et que la page AI agents précise qu'un agent sans compétence ne peut que fournir des informations.

Et en Community ?

Community

Odoo 20 Community ne contient aucun module d'IA : ni application IA, ni icône « Demander à l'IA », ni bouton IA dans les champs de texte. Elle contient en revanche les règles d'automatisation (base_automation), installées ici avec l'application, et, dans le CRM, la probabilité calculée automatiquement à côté de la probabilité saisie sur une opportunité ; ce calcul ne fait pas appel à un agent.

Pour retrouver à la main ce que l'agent a présenté à l'étape 5, le pipeline et ses étapes sont décrits dans Le pipeline d'opportunités du CRM d'Odoo 20, écrit pour la Community, et son analyse dans Prévisions et analyse du pipeline dans Odoo 20. L'édition Enterprise ajoute la question posée en langage courant et le texte rédigé à partir de la fiche.

Points de vigilance

Une réponse varie d'un essai à l'autre

La même demande de description, posée deux fois sur la même opportunité, a donné deux textes différents (le premier parlait d'un « projet de conseil », le second d'un « besoin de 20 bureaux associé à du conseil »). Relisez chaque texte avant de l'utiliser et, pour un chiffre à communiquer, recoupez-le avec le menu Analyse de l'application concernée.

Utiliser ceci n'enregistre pas la fiche

Le texte inséré par Utiliser ceci reste une modification en cours : il faut enregistrer la fiche pour le garder, ou ignorer les modifications pour revenir en arrière. La relecture se fait dans le champ, avant l'enregistrement.

Chaque ouverture crée une conversation

Pendant les essais, chaque clic sur l'icône Demander à l'IA ou sur le bouton IA d'un champ a ouvert une nouvelle conversation, rangée dans Discussion › IA, y compris quand aucune question n'a été posée. Pour poursuivre un échange, utilisez le lien « Reprendre le chat précédent » ou rouvrez la conversation dans Discussion.

Exercice

Objectif : poser une question à l'agent sur les données de démonstration et vérifier sa réponse.

Indication : ouvrez Demander à l'IA depuis la barre du haut et demandez, par exemple, quelles opportunités sont suivies par Marc Demo. Dépliez Étapes effectuées, puis ouvrez CRM › Ventes › Mon pipeline, retirez le filtre proposé par défaut et filtrez sur ce vendeur.

Critère de réussite : les étapes montrent la compétence Search Database, et les opportunités citées par l'agent sont celles que le filtre du CRM affiche, avec les mêmes montants.

À retenir

  • L'application IA est propre à l'édition Enterprise ; elle installe aussi les règles d'automatisation.
  • Un agent se définit par ses instructions, ses compétences, ses sources et ses déclencheurs ; huit agents sont livrés, dont Odoo AI, l'assistant généraliste.
  • Les compétences décident de ce que l'agent peut faire : Search Database pour lire la base, Update Records et Create Records pour la modifier.
  • Une question posée par Demander à l'IA s'appuie sur les données de la base ; Étapes effectuées montre ce que l'agent a consulté.
  • Le bouton IA d'un champ de texte rédige à partir de la fiche ; Utiliser ceci insère le texte, l'enregistrement reste à faire.
