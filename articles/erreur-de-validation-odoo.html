Erreur de validation dans Odoo 20 : messages et solutions

Un clic sur Enregistrer, et Odoo 20 répond par une fenêtre « Erreur de validation » ou un bandeau rouge. Le message n'est pas une panne : il nomme la règle que la saisie enfreint. Cet article montre comment le lire et comment corriger les messages les plus fréquents, dont « Les contacts nécessitent un nom ».

~5 minutes de lecture · niveau débutant · série Astuces Odoo 20

Édition : Community. Écrit et vérifié sur Odoo 20.0 Community, octobre 2026, sur la base de démonstration, société My Company (San Francisco) (applications Contacts et Inventaire). Ces messages existent aussi dans l'édition Enterprise.

La réponse en bref

  1. Lisez le texte sous le titre : il dit quelle valeur pose problème.
  2. Cliquez sur Fermer : votre saisie reste en place, rien n'est enregistré.
  3. Corrigez la valeur et enregistrez à nouveau, ou abandonnez avec Ignorer tous les changements (la croix).
  4. À l'import, « Les contacts nécessitent un nom » signale une ligne sans nom : complétez-la dans le fichier, puis Charger à nouveau.

1. Lire la fenêtre avant de la fermer

Odoo 20 choisit le titre de la fenêtre selon la nature du refus. Le titre suffit souvent à savoir où chercher :

Titre affichéCe qu'il signifieOù agir
Erreur de validationUne valeur saisie enfreint une règle sur les données (doublon, champ vide, incohérence).Corriger la valeur nommée dans le message.
Opération invalideOdoo refuse l'action demandée, par exemple sur une période verrouillée.Suivre la raison donnée dans le message.
Erreur d'accèsL'utilisateur n'a pas les droits nécessaires sur ce document.Un administrateur ajuste les droits.

Une erreur de validation bloque l'enregistrement en entier : aucune des modifications en cours n'est écrite. Le bouton Fermer ramène au formulaire avec la saisie intacte. Deux sorties sont alors possibles : corriger puis cliquer de nouveau sur Enregistrer manuellement (le nuage), ou cliquer sur la croix Ignorer tous les changements pour revenir aux valeurs d'origine.

2. « Champs obligatoires manquants »

C'est le message le plus courant, et il ne prend pas la forme d'une fenêtre : un bandeau rouge apparaît en haut à droite, et le champ à remplir se colore en rose. Le formulaire bloque l'enregistrement avant même d'interroger le serveur. Sur un contact créé par Contacts › Nouveau puis enregistré sans nom :

Remplissez le champ coloré et enregistrez. Le même bandeau apparaît dans les fenêtres de saisie, par exemple Ajouter Contacts liés sur la fiche d'une entreprise, quand le nom de la personne est laissé vide.

3. « Les contacts nécessitent un nom » à l'import

Ce message vient d'une règle de la base de données : tout partenaire de type Contact doit avoir un nom. Le formulaire l'empêche en amont (bandeau de la section précédente) ; c'est donc surtout à l'import d'un fichier qu'il apparaît, quand une ligne a une cellule Nom vide.

  1. Dans Contacts, ouvrez le menu ⋮ (info-bulle « Actions ») à côté du titre, puis Importer.
  2. Chargez le fichier et cliquez sur Tester.
  1. Complétez le nom dans le fichier, enregistrez-le, puis cliquez sur Charger à nouveau et testez encore.
  2. Quand le bandeau indique « Tout semble correct. », cliquez sur Importer.

Tant qu'une erreur subsiste, Odoo n'importe rien, pas même les lignes correctes : sur la base de démonstration, un clic sur Importer avec ce fichier n'a créé aucun contact. Il n'y a donc pas de doublons à nettoyer après une tentative échouée.

La règle ne vise que le type Contact. Une ligne sans nom dont la colonne Type d'adresse vaut Livraison (ou Facture, Autre) passe le test : c'est le cas des adresses secondaires d'un client, qui n'ont pas toujours de nom propre.

4. Un code-barres déjà attribué

Deux produits ne peuvent pas partager le même code-barres. Sur la base de démonstration, saisir sur la fiche Lampe de bureau le code-barres du produit Pied de table donne cette fenêtre :

Le texte nomme le produit concurrent : « Barcode "10133785575281" already assigned to product: Pied de table ». Pour le retrouver, collez le code dans la barre de recherche de Ventes › Produits › Produits : la fiche Pied de table s'affiche. Décidez alors quel produit garde le code, retirez-le de l'autre, puis enregistrez. La remarque finale rappelle qu'un produit que l'utilisateur n'a pas le droit de voir peut aussi bloquer : si la recherche ne trouve rien, un administrateur doit vérifier.

Le même raisonnement vaut pour toutes les erreurs de validation de type « déjà utilisé » : le message cite la valeur, il reste à trouver l'enregistrement qui la porte.

Point de vigilance : le numéro de ligne de l'import

Dans « Erreur à la ligne 1 », Odoo compte les lignes de données à partir de 0 : la première ligne sous l'en-tête est la ligne 0. Sur la base de démonstration, un nom vide en première ligne de données donne « Erreur à la ligne 0 ». Dans un tableur où l'en-tête occupe la ligne 1, l'erreur « ligne N » se trouve donc à la ligne N + 2. Vérifiez la ligne avant de corriger, sous peine de modifier la mauvaise.

À retenir

  • Une erreur de validation n'enregistre rien ; Fermer garde la saisie pour la corriger.
  • Champs obligatoires manquants : remplissez le champ coloré en rose.
  • Les contacts nécessitent un nom : une ligne d'import de type Contact sans nom ; l'import entier attend la correction.
  • Un message « déjà attribué » cite la valeur : cherchez-la pour trouver le doublon.
