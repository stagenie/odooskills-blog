Étiquettes produits et codes-barres dans Odoo 20

Étiqueter un rayon, une réception ou un lot de cartons demande une planche avec le nom, la référence, le prix et un code-barres lisible. Odoo 20 Community les imprime en PDF depuis la liste des produits, sans module supplémentaire. Il reste à savoir où se trouve la commande et quel format choisir.

~5 minutes de lecture · niveau débutant · série Astuces Odoo 20

Édition : Community. Écrit et vérifié sur Odoo 20.0 Community, octobre 2026, sur la base de démonstration, société My Company (San Francisco), avec les applications Inventaire et Ventes installées. Ces modules existent aussi dans l'édition Enterprise.

La réponse en bref

  1. Renseignez le champ Code-barres de chaque fiche produit.
  2. Dans Inventaire › Produits › Produits, vue liste, cochez les produits.
  3. Menu Actions › Imprimer les étiquettes : choisissez le type, le nombre de copies, le format et, au besoin, une liste de prix.
  4. Cliquez sur Imprimer : Odoo télécharge un PDF prêt pour la planche d'étiquettes.

1. Donner un code-barres au produit

L'étiquette reprend ce qui figure sur la fiche : le nom, la Référence et le Code-barres. Ouvrez le produit depuis Inventaire › Produits › Produits ; le champ se trouve dans l'onglet Informations générales, colonne de droite, sous la référence. Saisissez le code (celui du fabricant, ou un code interne) et enregistrez.

Odoo refuse un code déjà porté par un autre produit. À l'enregistrement, la fenêtre « Erreur de validation » indique « Code(s)-barres déjà attribué(s) » et nomme le produit qui l'utilise. Le champ n'apparaît pas sur un produit de type Service ou Combo.

2. Lancer l'impression depuis la liste

  1. Ouvrez Inventaire › Produits › Produits et passez en vue liste.
  2. Cochez les produits à étiqueter (ici, les quatre résultats d'une recherche « tiroir »).
  3. Ouvrez le menu Actions et choisissez Imprimer les étiquettes.

La même entrée existe dans le menu Actions (roue dentée) d'une fiche produit ouverte, y compris depuis l'application Ventes.

3. Régler la fenêtre « Imprimer les étiquettes »

ChampEffet
TypeBarcode 1D : code-barres à barres verticales. QR Code : code carré à deux dimensions (le modèle d'étiquette utilise la symbologie Data Matrix) ; vérifiez que votre lecteur lit les codes 2D.
CopiesNombre d'étiquettes par produit : 2 copies pour 4 produits donnent 8 étiquettes.
Format2 x 7, 4 x 7, 4 x 12 : planches A4 de 14, 28 ou 48 étiquettes (colonnes x lignes). Dymo : une étiquette par page de 57 x 32 mm. Étiquettes ZPL : un fichier texte pour imprimante thermique ZPL, avec choix du gabarit et aperçu.
Imprimer avec le prixCoché par défaut. Décochez pour une étiquette sans prix.
Liste de prixVide, Odoo imprime le Prix de vente de la fiche. Avec une liste, il imprime le prix de cette liste, dans sa devise.
Contenu supplémentaireTexte libre ajouté à l'étiquette ; visible seulement avec le format 2 x 7.

Le champ Conditionnement, présent sur la base de démonstration où les unités de mesure sont activées, imprime le code-barres d'un conditionnement (un carton, par exemple) plutôt que celui de l'unité. La fenêtre retient, pour chaque utilisateur, le dernier type et le dernier format imprimés : vérifiez-les avant de cliquer sur Imprimer.

4. Le PDF obtenu

Le clic sur Imprimer ferme la fenêtre et télécharge un PDF. Chaque étiquette porte le code-barres et son numéro en clair, le nom, la référence interne et le prix. Des repères de coupe marquent les angles de chaque case.

Le prix imprimé est celui de la fiche ou de la liste, sans les taxes : le Tiroir noir à 25,00 $ (28,75 $ toutes taxes comprises, d'après sa fiche) sort à 25,00 $ sans liste de prix, et à 19,48 € avec la liste EUR de la base de démonstration. Si ce montant ne convient pas en rayon, décochez Imprimer avec le prix.

5. Étiqueter une réception entière

Pour coller une étiquette sur chaque article reçu, partez du bon de réception plutôt que de la liste des produits. Ouvrez la réception (Inventaire › Opérations › Réceptions), puis le menu Actions › Imprimer › Libellés. La fenêtre s'intitule « Choisir le modèle d'étiquettes » et propose un champ Quantité à imprimer réglé sur Quantités de l'opération : Odoo imprime autant d'étiquettes que d'unités sur le bon. Sur la base de démonstration, la réception WH/IN/00002 de 35 chaises de bureau donne 35 étiquettes sur 3 pages au format 2 x 7. Choisissez Personnalisé pour revenir à un nombre de copies fixe.

Point de vigilance : un produit sans code-barres

Odoo imprime l'étiquette d'un produit dont le champ Code-barres est vide, sans avertissement : la case porte le nom, la référence et le prix, mais aucun code (produit Tiroir de la planche ci-dessus). Avant une grande impression, ajoutez la colonne Code-barres à la liste des produits (icône de réglage des colonnes) et repérez les cases vides. Les services, eux, sont refusés : « Les étiquettes ne peuvent pas être imprimées pour les produits de type service. »

À retenir

  • L'impression part du menu Actions › Imprimer les étiquettes de la liste ou de la fiche produit.
  • Copies compte par produit ; depuis une réception, Odoo suit les quantités reçues.
  • Le prix imprimé vient de la fiche ou de la liste de prix choisie, hors taxes.
  • Un produit sans code-barres sort sans code : vérifiez le champ avant d'imprimer.
