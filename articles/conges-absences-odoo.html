Congés et absences dans Odoo 20

Un congé se gère en trois temps : l'entreprise attribue des jours, l'employé les demande, son responsable valide. L'application Congés d'Odoo 20 relie ces trois gestes et tient le solde à jour sans tableur.

~8 minutes de lecture · niveau débutant · série Ressources humaines avec Odoo 20

Édition : Community. Écrit et vérifié sur Odoo 20.0 Community, septembre 2026, sur la base de démonstration. L'application Congés est incluse dans la Community.

Avant de commencer

Chaque congé est rattaché à une fiche employé : l'article précédent de la série, sur les employés et l'organigramme, montre comment la remplir. L'application Congés s'installe depuis Applications ; sa carte porte encore le nom anglais Time Off.

Deux personnes de la démonstration servent d'exemple : Marc Demo, l'employé, et Mitchell Admin, son manager. Parce que Mitchell Admin est le manager de Marc Demo, il est aussi, par défaut, celui qui valide ses congés.

Objectifs

À la fin de cet article, vous saurez :

  • lire le tableau de bord de vos congés ;
  • régler un type de congé : allocation et circuit de validation ;
  • attribuer des jours à un employé ;
  • déposer une demande de congé, puis la valider en tant que responsable.

1. Lire son tableau de bord

L'application s'ouvre sur Mes congés. En haut, une tuile par type de congé indique les jours disponibles et, s'il y en a une, leur date limite de validité. Dessous, le calendrier de l'année montre les congés déjà posés ; à droite, la légende distingue les congés approuvés, à approuver et refusés, suivie des jours obligatoires et des jours fériés.

Le menu résume l'application : My Time pour vos propres congés, Vue d'ensemble pour le calendrier de l'équipe, Management pour les demandes à traiter, Analyse pour les soldes, et Configuration pour les types, les jours fériés et les règles. Marc Demo, qui n'administre pas l'application, ne voit que les trois premiers : Management apparaît parce qu'il valide lui-même les congés d'un collègue.

2. Régler un type de congé

Dans Odoo 20, un type de congé est un type d'entrée de travail : la même liste sert aux congés, aux présences et à la paie. Elle s'ouvre par Configuration › Types d'entrée de travail. Ouvrez Congé compensatoire.

Le haut du formulaire décrit le temps lui-même : Considéré comme Absence, compté en Jours, avec un Type de durée Demi-journée. La case Congés de la ligne Availability le rend proposable dans les demandes. L'onglet Congés règle le reste :

  • Demandes de congés › Validation : qui approuve une demande. Ici, Par l'approbateur de l'employé, c'est-à-dire l'approbateur des congés inscrit sur sa fiche, par défaut son manager ;
  • Nécessite une allocation : l'employé ne peut poser que des jours qui lui ont été attribués ;
  • Autoriser les demandes des employés : l'employé peut réclamer lui-même une allocation, validée ici Par le responsable RH ;
  • Configuration : solde négatif autorisé ou non, jours ouvrés ou calendaires, jours fériés ignorés ou non, justificatif attendu.

3. Attribuer des jours

Marc Demo récupère des heures faites pendant un salon professionnel : cinq jours. Management › Allocations, puis Nouveau : choisissez le type Congé compensatoire, saisissez 5 jours, l'employé Marc Demo et un motif. La période de validité démarre aujourd'hui ; laissée vide, sa fin vaut Sans limites.

Enregistrée, l'allocation est À approuver, et une activité de validation est créée. Le bouton Valider la fait passer à Approuvé : l'employé reçoit un message qui confirme les jours, et sa tuile affiche désormais 5 jours disponibles.

4. Demander un congé

Connecté comme Marc Demo, ouvrez Mes congés et cliquez sur le bouton Nouveau. Deux choix apparaissent : Nouvelle demande de congé pour poser des jours, Nouvelle demande d'allocation pour en réclamer.

Choisissez Nouvelle demande de congé. Le type affiche le solde entre parenthèses : « 5 restant sur 5 jours ». Cliquez sur la date de début, puis sur la date de fin, pour choisir du 12 au 13 octobre. Comme le type se demande par demi-journée, Odoo propose une demi-journée de départ et une demi-journée de retour ; laissées à Matin et Après-midi, elles couvrent les deux journées entières. La durée calculée, 2 jours, s'affiche dessous. Une description aide le responsable à décider.

Soumettre la demande l'enregistre à l'état À approuver. Sur le calendrier, les jours demandés apparaissent hachurés, comme l'indique la légende.

5. Valider la demande

Côté Mitchell Admin, Management › Congés s'ouvre sur le filtre En attente de ma signature : seules les demandes qu'il doit traiter y figurent. Chaque ligne porte déjà une icône pour approuver et une autre pour refuser. Ouvrez la demande de Marc Demo pour la lire en entier.

L'encadré Résumé 2026 récapitule, par type, les jours déjà pris par l'employé dans l'année ; ici, 6 jours de Guaranted monthly wage illness. Valider fait passer la demande à Approuvé ; un bouton Retour à la validation permet de revenir en arrière. La tuile de Marc Demo tombe à 3 jours disponibles.

Vue d'ensemble affiche ensuite le congé sur le calendrier de l'équipe, et Analyse présente les soldes par employé et par type.

En Community. Types de congés, allocations, plans de cumul de congés, jours fériés, jours obligatoires, règles automatiques, demandes, validation à un ou deux niveaux, vue d'ensemble et analyses sont inclus dans Odoo 20 Community.

Points de vigilance

La tuile « Nouvelle demande » ne demande pas un congé

Sur le tableau de bord, la tuile grise Nouvelle demande ouvre une Nouvelle allocation : elle réclame des jours, elle n'en pose pas. Pour poser un congé, passez par le bouton Nouveau.

Des types en double dans la configuration

La liste des types d'entrée de travail peut montrer deux fois le même nom : un type générique et un type propre à un pays. Une demande de congé ne propose que les types du pays de la société, ou les types sans pays si ce pays n'en a aucun. Réglez donc le type du pays de votre société, sinon vos changements n'apparaîtront pas dans les demandes.

Exercice

Objectif : faire réclamer une allocation par l'employé lui-même.

Indication : connecté comme Marc Demo, choisissez Nouveau › Nouvelle demande d'allocation, type Congé compensatoire, 1 jour. Reconnectez-vous comme Mitchell Admin et validez-la depuis Management › Allocations.

Critère de réussite : la tuile Congé compensatoire de Marc Demo gagne un jour.

À retenir

  • Dans Odoo 20, un type de congé est un type d'entrée de travail.
  • Un type qui nécessite une allocation ne se pose qu'après l'attribution de jours.
  • Le circuit de validation se règle par type : personne, le responsable RH, l'approbateur de l'employé, ou les deux.
  • L'approbateur des congés de la fiche employé, par défaut son manager, valide ses demandes.
