Promotions et codes promo : les 8 programmes d'Odoo 20

Une remise dès un certain montant, un code à diffuser dans une campagne, des bons à usage unique à distribuer sur un salon : Odoo 20 traite ces trois besoins, et cinq autres, avec un seul moteur de programmes. Cet article les passe en revue, puis en met trois en œuvre sur un devis.

~10 minutes de lecture · niveau débutant · série Remises et promotions avec Odoo 20

Édition : Community. Écrit et vérifié sur Odoo 20.0 Community, octobre 2026, sur la base de démonstration avec Ventes, Site Web, eCommerce et Point de vente installés. Les programmes de promotion existent aussi dans l'édition Enterprise.

Avant de commencer

Une liste de prix fixe le prix d'un client ou d'une quantité ; un programme accorde une récompense quand une condition est remplie : un montant atteint, un article acheté, un code saisi. La récompense prend la forme d'une ligne négative sur le devis, ou d'un article offert. Les deux mécanismes se cumulent. Les listes de prix et le bouton Remise sont présentés dans Listes de prix et remises dans Odoo 20 ; le présent article ne traite que des programmes.

Tout programme se construit de la même façon : un type, une ou plusieurs règles conditionnelles (quand la récompense est-elle due ?) et une ou plusieurs récompenses (que reçoit le client ?).

Objectifs

À la fin de cet article, vous saurez :

  • activer les programmes de promotion depuis Ventes ;
  • choisir le bon type parmi les huit proposés ;
  • créer une promotion automatique et l'appliquer à un devis ;
  • diffuser un code promo utilisable une seule fois par client ;
  • générer des bons de réduction à usage unique.

1. Activer les programmes

Ouvrez Ventes › Configuration › Paramètres. Dans le bloc Tarif, cochez Promotions, Fidélité & Cartes-Cadeaux, puis cliquez sur Enregistrer.

L'enregistrement installe le module des programmes, et avec lui un module de liaison pour chaque application déjà présente : Ventes, boutique en ligne, point de vente, frais de livraison. Sur la base de démonstration, sept modules s'ajoutent. Odoo revient ensuite sur Ventes, qui compte un nouveau menu Promotions à deux entrées : Remise & Fidélité et Cartes-cadeaux & e-wallet.

Avec la démonstration, la liste Remise & Fidélité n'est pas vide : six programmes d'exemple y figurent (un code de 10 %, un « achetez 3, recevez-en un », des bons de 10 %, un bon pour la prochaine commande, un programme de fidélité, une livraison gratuite). Ils sont actifs, ce qui compte pour la suite.

2. Les huit types de programmes

Dans Ventes › Promotions › Remise & Fidélité, cliquez sur Nouveau. Le champ Type propose six types ; les deux types qui servent à payer, carte-cadeau et e-wallet, se créent depuis l'autre entrée du menu.

Changer de type pré-remplit une règle et une récompense d'exemple, et affiche sous le champ une phrase d'aide. Le tableau les résume.

Pour une remise ponctuelle, trois types suffisent dans la plupart des cas : Promotions, Code de remise et Bons de réduction. Les sections suivantes les mettent en œuvre. La fidélité et les cartes-cadeaux, qui suivent un client dans le temps, relèvent d'un article à part.

3. Une promotion automatique : 10 % dès 1 000 $

Toujours sur le nouveau programme, laissez le type Promotions et nommez-le « 10 % dès 1 000 $ d'achat ». La règle pré-remplie dit « Si minimum 50,00 dépensé » : cliquez dessus et passez l'Achat minimum à 1000.

La règle peut aussi exiger une quantité minimale, ou ne compter que certains produits, catégories ou étiquettes. Cliquez sur Enregistrer & Fermer. La récompense pré-remplie, « 10,00% de remise sur votre commande », convient ; enregistrez le programme.

Au-dessus des onglets, trois champs limitent le programme : Limite d'utilisation (un nombre maximal de commandes), Pour (certaines listes de prix seulement) et Availability Dates (une période de validité, dates incluses).

Créez ensuite un devis pour Acme Corporation avec un Grand bureau à 1 799 $, et enregistrez. Aucune remise n'apparaît : sur un devis, une promotion « automatique » ne s'applique pas seule. Sous les lignes, cliquez sur Récompense.

Odoo liste toutes les récompenses auxquelles le devis donne droit. Le programme de démonstration « Livraison gratuite » se déclenche lui aussi à partir de 1 000 $. Choisissez « 10 % dès 1 000 $ d'achat », puis Appliquer.

La remise prend la forme d'une ligne « 10% sur votre commande », soumise à la même taxe que l'article. Sous le total, une ligne nouvelle d'Odoo 20, Total Advantage, additionne les avantages accordés au client, taxes comprises : ici 179,90 $ + 15 % = 206,89 $.

4. Un code promo, une seule fois par client

Le code promo convient à une campagne : courriel, réseau social, flyer. Créez un programme de type Code de remise nommé « Bienvenue : 15 % sur la première commande ». Cliquez sur la règle pré-remplie (« Code de remise PROMO_CODE_… »), remplacez le code par BIENVENUE15 et l'achat minimum par 0. Passez la récompense à 15 %.

Cochez enfin Once per user (« une fois par client »), une case qui apparaît en Odoo 20, réservée au type Code de remise.

Sur un devis pour Azure Interior (deux « Combinaison de bureau »), cliquez sur Code promotionnel et saisissez le code.

Appliquer ouvre la fenêtre Récompenses disponibles, comme à l'étape 3 : sélectionnez la récompense du code et appliquez-la.

Azure Interior bénéficie déjà de la liste de prix « Grossiste » créée dans l'article sur les listes de prix : 10 % dans la colonne Rem.%. Le code ne la remplace pas, il s'y ajoute : 15 % des 810 $ déjà remisés, soit −121,50 $. Total Advantage additionne les deux avantages, taxes comprises : (90 + 121,50) × 1,15 = 243,23 $. Sans cette liste de prix, le code s'applique aux 900 $ : −135 $.

Confirmez le devis. Odoo inscrit alors Azure Interior parmi les clients qui ont utilisé le code. Sur un nouveau devis pour le même client, le même code est refusé :

Le message est resté en anglais : « ce code promo ne peut être utilisé qu'une fois ». Le contrôle porte sur le client, pas sur le code : un autre client peut toujours l'utiliser. Sur la boutique en ligne, un visiteur non connecté doit d'abord se connecter pour utiliser un tel code.

5. Des bons de réduction à usage unique

Un code partagé circule ; un bon de réduction, lui, est unique et ne sert qu'une fois. La démonstration contient le programme « Bon de réduction de 10% ». Ouvrez-le et cliquez sur Générer des bons de réduction.

Deux modes : Clients anonymes produit le nombre de bons demandé, à distribuer librement ; Clients sélectionnés crée un bon par client choisi (ou par client portant une étiquette) et, quand le programme prévoit un courriel à la création des bons (c'est le cas ici), l'envoie à chaque client. La Description est obligatoire. Saisissez 3 bons, une date de fin de validité, puis cliquez sur Générer Bons de réduction.

Le bouton intelligent Bons de réduction du programme liste les codes :

Chaque bon porte un solde d'un point, que la récompense consomme. Les boutons Envoyer et Partager le transmettent à un client. Saisissez l'un des codes (ici 0444-52de-4a6a) avec le bouton Code promotionnel d'un devis, puis choisissez la récompense.

Après confirmation de la commande, le même code saisi sur un autre devis donne « Ce bon de réduction a déjà été utilisé. » Un bon expiré est refusé de la même façon.

6. Les mêmes programmes en boutique et en caisse

Un programme n'appartient pas aux Ventes : l'onglet Settings de chaque programme indique où il s'applique.

Les cases Disponible sur apparaissent avec les modules de liaison installés à l'étape 1 : Ventes pour les devis, Site Web pour la boutique en ligne, Point of sale pour la caisse. Les champs du dessous restreignent le programme à un site ou à certains points de vente. Une promotion de fin de saison peut ainsi viser la seule boutique en ligne, un code « magasin » la seule caisse.

En Community. Les huit types de programmes, la génération de bons et leur usage dans les devis, la boutique en ligne et le point de vente sont inclus dans Odoo 20 Community. Pour les cartes de fidélité, Odoo 20 ajoute aussi une durée de validité des points (Points Validity, en jours), présentée avec la fidélité.

Points de vigilance

Une récompense oubliée n'arrête pas la confirmation

Sur un devis, rien ne s'applique tant que personne ne clique sur Récompense ou Code promotionnel. Si le commercial confirme un devis éligible sans le faire, Odoo affiche seulement « Il existe des récompenses disponibles non ajoutées à cette commande. » : la commande est confirmée, sans la remise.

Le minimum d'achat est taxes comprises

L'Achat minimum d'une règle vaut taxes incluses par défaut. Un minimum de 1 000 $ est donc atteint avec 870 $ hors taxes à 15 %. Pour un seuil hors taxes, choisissez « taxes exclues » à côté du montant.

Les programmes de démonstration sont actifs

Sur une base de démonstration, la livraison gratuite, la fidélité et le bon « prochaine commande » réagissent à chaque devis : à la confirmation de la commande d'Azure Interior, Odoo a créé une carte de fidélité et un bon pour sa prochaine commande. Archivez les programmes d'exemple avant d'utiliser la base pour de vrai.

Exercice

Objectif : retrouver et utiliser un code de la démonstration, puis vérifier que « Once per user » ne vise que le client qui a déjà utilisé le code.

Indication : ouvrez le programme « Code pour 10% de remise sur les commandes » et lisez le code de sa règle (10pc). Sur un devis pour Wood Corner avec deux « Combinaison de bureau », appliquez ce code avec le bouton Code promotionnel, puis saisissez aussi BIENVENUE15.

Critère de réussite : le devis porte une ligne « Remise 10% de réduction sur votre commande » de −90,00 $ (10 % de 900 $) ; le code BIENVENUE15, refusé à Azure Interior, est accepté pour Wood Corner.

À retenir

  • Les programmes s'activent dans Ventes › Configuration › Paramètres, bloc Tarif, et se gèrent dans Ventes › Promotions.
  • Huit types : six dans Remise & Fidélité, carte-cadeau et e-wallet dans l'autre menu.
  • Un programme = un type, des règles, des récompenses ; la récompense devient une ligne négative du devis, qui s'ajoute aux remises de la liste de prix.
  • Sur un devis, les boutons Récompense et Code promotionnel appliquent les programmes ; rien ne s'applique seul.
  • Nouveau en Odoo 20 : « Once per user » pour les codes de remise et la ligne Total Advantage sous le total du devis.
