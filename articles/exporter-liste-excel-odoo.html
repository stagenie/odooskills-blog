Exporter une liste vers Excel dans Odoo 20

Contacts, commandes, factures, produits : toute liste d'Odoo 20 part vers un tableur en quelques clics. Le choix des colonnes s'enregistre dans un modèle d'export, pour obtenir le même fichier la fois suivante sans tout recocher.

~5 minutes de lecture · niveau débutant · série Astuces Odoo 20

Édition : Community. Écrit et vérifié sur Odoo 20.0 Community, octobre 2026, sur la base de démonstration. L'export fait partie du client web d'Odoo ; il existe aussi dans l'édition Enterprise.

L'exemple exporte les contacts de la démonstration. La méthode est la même dans toutes les applications : elle part d'une liste (ou d'une vue kanban) et de lignes cochées.

La réponse en bref

  1. Dans la liste, cochez les lignes à exporter (ou la case d'en-tête, puis Tout sélectionner).
  2. Cliquez sur Actions › Exporter.
  3. Composez la colonne Champs à exporter, choisissez le format .xlsx ou .csv.
  4. Enregistrez ce choix comme modèle (icône nuage), puis cliquez sur Exporter.

1. Sélectionner les lignes et ouvrir Exporter

Ouvrez l'application Contacts et passez en vue liste par l'icône à lignes, en haut à droite. Filtrez si besoin, puis cochez les fiches voulues. Le bandeau indique 4 sélectionné(s) et le bouton Actions apparaît : Exporter est la première entrée.

Pour exporter toute la liste, cochez la case de l'en-tête : Odoo coche les 80 lignes de la page et propose Tout sélectionner 107. Un clic sur ce bouton étend la sélection à toutes les fiches qui répondent aux filtres en cours (Tous 107 sélectionné(s)), y compris celles des pages suivantes.

Le menu Exporter n'apparaît que pour les utilisateurs qui ont le droit d'exporter (réglage Export de la fiche utilisateur, accordé d'office aux administrateurs).

2. Choisir les colonnes, y compris des champs liés

La fenêtre Exporter les données s'ouvre avec, à droite, les colonnes affichées dans la liste (ici Avatar 128, Nom d'affichage, E-mail, Téléphone, Activités, Pays, Stats). Retirez les colonnes inutiles par leur corbeille ; ajoutez-en depuis Champs disponibles avec la zone Rechercher... et le + au bout de chaque ligne. Les flèches de gauche permettent de réordonner les colonnes par glisser-déposer.

Un champ précédé d'une flèche › renvoie à une autre fiche : déroulez-le pour atteindre ses propres champs. Sous Société associée, le champ Nom ajoute la colonne Société associée/Nom, c'est-à-dire la société de chaque contact.

Le champ Format propose Excel Workbook (.xlsx) et Plain Text (.csv). Le fichier xlsx s'ouvre tel quel dans un tableur ; le fichier csv, séparé par des virgules, sert aux échanges avec d'autres logiciels. Dans le csv, une valeur qui commence par +, - ou = reçoit une apostrophe devant elle ('+971 200 123 4571), pour qu'un tableur ne la prenne pas pour une formule.

3. Enregistrer et réutiliser le modèle d'export

Une fois les colonnes en place, cliquez sur l'icône nuage à droite de Select a template..., saisissez un nom (« Annuaire contacts ») et validez par la coche. Le modèle apparaît dans la liste déroulante, avec un crayon pour le modifier et une corbeille pour le supprimer.

À l'ouverture suivante, la fenêtre repart des colonnes de la liste : choisissez Annuaire contacts dans la liste déroulante et les sept colonnes reviennent, dans le même ordre. Le modèle retient les champs, pas le format ni l'option de l'étape 4 : vérifiez-les avant de cliquer sur Exporter.

Un modèle est propre à un type de fiche (celui des contacts ne s'affiche pas sur les factures) et il est commun à tous les utilisateurs autorisés à exporter : un collègue le voit, peut le modifier ou le supprimer. Un nom explicite évite les mauvaises surprises.

4. Ouvrir le fichier et choisir le bon mode

Le téléchargement s'appelle Contact (res.partner).xlsx. La première ligne reprend les libellés des colonnes, puis une ligne par contact. Avec les 107 contacts de la démonstration, le fichier compte pourtant 111 lignes : un contact qui porte plusieurs étiquettes occupe plusieurs lignes, la deuxième étiquette se trouvant sur une ligne suivante dont les autres cellules sont vides.

Ce découpage gêne un tri ou un tableau croisé. L'interrupteur Updatable fields only, en haut de la fenêtre, change le fichier : les étiquettes sont regroupées dans une seule cellule, séparées par des virgules ; une colonne id ajoute l'identifiant de chaque fiche (base.res_partner_2 pour Acme Corporation) ; les en-têtes deviennent les noms techniques (email, parent_id/name, category_id) ; la liste de gauche ne montre plus que les champs modifiables. Les colonnes déjà retenues à droite restent en place : remplacez Nom d'affichage, calculé par Odoo, par le champ Nom. C'est le mode à retenir pour corriger les fiches dans le tableur puis les réimporter : Odoo reconnaît chaque ligne par sa colonne id et met à jour la fiche au lieu d'en créer une nouvelle.

Quand plusieurs langues sont installées et qu'un champ traduisible figure dans l'export, la fenêtre affiche aussi un champ Languages : une colonne par langue choisie, nouveauté d'Odoo 20.

Exporter sans rien cocher

Sans ligne cochée, le menu ⋮ à côté du titre de la liste propose aussi Exporter. Celui-ci télécharge aussitôt toute la liste filtrée en xlsx, sans ouvrir la fenêtre : le fichier reprend les colonnes affichées telles quelles, Avatar 128 compris, sous forme d'un long texte codé, et la colonne Stats en texte technique. Pour choisir les colonnes ou utiliser un modèle, cochez les lignes et passez par Actions › Exporter.

À retenir

  • Cochez les lignes (ou Tout sélectionner) puis Actions › Exporter : la fenêtre part des colonnes de la liste.
  • La flèche › d'un champ donne accès aux champs de la fiche liée, comme Société associée/Nom.
  • Le modèle d'export garde les colonnes, pas le format ; il est partagé entre les utilisateurs autorisés.
  • Updatable fields only produit un fichier prêt à réimporter : colonne id, une ligne par fiche.
