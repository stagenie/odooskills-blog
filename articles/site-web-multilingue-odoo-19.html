Activer plusieurs langues sur ton site, laisser le sélecteur de langue apparaître tout seul, voir l'arabe retourner la page entière en RTL — barre de navigation, logo et boutons compris — puis récolter, sans rien faire, un vrai référencement multilingue. Le tout depuis l'interface.

~12 minutes de lecture · démonstration Français → Arabe (RTL)

Ce que tu vas apprendre

① Ajouter des langues à ton site web

Un site Odoo a sa propre liste de langues, distincte du reste de la base. On la complète en quelques clics dans la configuration du site.

② Le sélecteur de langue, automatique

Dès qu'un site propose plus d'une langue, un menu déroulant apparaît dans la barre de navigation. Chaque langue a son URL, et le visiteur choisit la sienne.

③ Le RTL gratuit, et la traduction du contenu

L'arabe bascule tout le site en RTL sans réglage. Reste à traduire ton contenu éditorial — ce que l'éditeur fait en mode « Traduire ».

Prérequis

  • Le module Site Web installé, avec au moins une page publiée.
  • Les langues visées déjà actives dans la base — le sujet du premier article de la série.
  • Un compte disposant des droits d'édition du site (concepteur / administrateur).

Trois réglages automatiques (langues → sélecteur → RTL), puis une seule tâche manuelle : traduire ton contenu.

1Ajouter des langues au site

Un point qui surprend souvent : activer une langue dans la base ne la propose pas automatiquement sur le site public. Le site tient sa propre liste de langues. On la règle dans la fiche du site — Site Web → Configuration → Paramètres, ou directement sur la fiche du site web.

Ajouter une langue ici, c'est tout ce qu'il faut pour que le site sache la servir. Le reste — le sélecteur, les URLs, le sens de lecture — en découle sans autre réglage.

2Le sélecteur de langue apparaît tout seul

Dès qu'un site propose au moins deux langues, Odoo ajoute un menu déroulant dans la barre de navigation. Le visiteur y voit chaque langue dans son propre alphabet et choisit la sienne ; le site mémorise ce choix pour la suite de la visite.

Chaque langue a sa propre adresse. La langue par défaut occupe la racine (/), les autres reçoivent un préfixe : /en pour l'anglais, /ar pour l'arabe. Ces URLs distinctes sont indexables séparément par les moteurs de recherche — un atout pour le référencement multilingue.

3L'arabe retourne le site de droite à gauche

C'est l'effet le plus spectaculaire. L'arabe est une langue qui s'écrit de droite à gauche (RTL) ; il suffit de basculer le site dessus pour que toute la mise en page s'inverse. Compare avec la version française :

La distinction est la clé du multilingue web : la coque du thème — libellés standards, boutons d'origine, bascule RTL — est fournie traduite par Odoo ; tout ce que tu as écrit ou renommé toi-même (contenu éditorial, menus personnalisés) n'est traduit que si tu le traduis, via le même mode « Traduire ».

4Traduire ton contenu en mode « Traduire »

Pour traduire tes pages, tu ne réécris rien : tu surtraduis l'existant. La marche à suivre :

  1. Depuis la barre supérieure de l'éditeur, ouvre le menu de langue et choisis Traduire (le bouton n'apparaît que sur une page servie dans une langue autre que celle par défaut — passe donc d'abord le site en arabe).
  2. La page repasse en affichage, mais chaque texte traduisible est maintenant surligné. Un clic dessus ouvre un champ où tu saisis la version arabe.
  3. Tu traverses ainsi le titre, les paragraphes, les libellés de boutons ; tu enregistres, et la page arabe affiche désormais ton contenu traduit — le reste du site, lui, n'a pas bougé.

Ce mode couvre tout ce que tu as écrit : pages, articles de blog, fiches produits, descriptions. Le principe est le même que le bouton de traduction d'un champ vu à l'article précédent, mais appliqué en contexte, directement sur la page telle que la verra le visiteur.

Bon réflexe : traduis d'abord ce qui compte pour la conversion — le bandeau d'accueil, les appels à l'action, les pages produits — avant de descendre dans les détails. Une page à moitié traduite reste lisible ; Odoo affiche le texte d'origine pour ce qui n'a pas encore de version dans la langue demandée.

5Le référencement multilingue, offert

Voici le bénéfice invisible mais décisif : en passant multilingue, ton site devient plusieurs sites indexables pour le prix d'un. Chaque langue a sa propre adresse, et Google la traite comme une page à part entière.

  • Une URL par langue : la langue par défaut occupe la racine (/), les autres reçoivent leur préfixe (/en, /ar). Trois langues, trois pages référençables pour un même contenu.
  • Les balises d'alternance linguistique sont générées toutes seules : Odoo indique à chaque moteur de recherche, sur chaque page, où trouver ses équivalents dans les autres langues (les balises hreflang), plus une version par défaut pour les visiteurs dont la langue n'est pas prévue. Résultat : le francophone tombe sur la page française dans les résultats, l'arabophone sur la page arabe.
  • Le plan du site (sitemap) liste les versions de chaque langue : rien à déclarer à la main, l'indexation multilingue se fait d'elle-même.

Concrètement, tu n'as qu'à ajouter les langues et traduire ton contenu : toute la plomberie SEO — adresses distinctes, alternances, plan du site — est posée par Odoo. C'est ce qui sépare un site « traduit » d'un site réellement trouvable dans chaque langue.

⚠️ Une langue du site ≠ une langue de la base

Le piège classique : activer une langue dans les paramètres généraux ne la fait pas apparaître sur le site public. Tant qu'elle n'est pas ajoutée aux langues du site (étape 1), le sélecteur l'ignore et l'URL préfixée renvoie une erreur.

À retenir aussi : les URLs par langue (/ar, /en) et les balises d'alternance linguistique sont générées automatiquement. Côté référencement, chaque version de langue est une page à part entière, correctement reliée à ses équivalents.

À retenir

  • Ajouter les langues dans la fiche du site — c'est le seul prérequis pour que le public y ait droit.
  • Le sélecteur et les URLs par langue (/ar, /en) apparaissent tout seuls, dès la deuxième langue.
  • Le RTL est intégral et gratuit : l'arabe retourne toute la mise en page, sans thème ni code.
  • Ton contenu — et tout menu renommé — se traduit en mode « Traduire », en contexte, sur la page elle-même ; les libellés standards du thème, eux, sont déjà traduits.

Quatre articles, un même fil : Odoo sépare partout la coque (traduite d'office) du contenu (à toi de le traduire), et rend l'arabe et le RTL accessibles sans une ligne de code. De l'interface backend au site public, tu as désormais toutes les portes d'entrée du multilingue.
