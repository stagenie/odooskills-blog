Essayer Odoo 20 Enterprise en ligne

Une base Odoo Enterprise s'ouvre depuis le site d'Odoo, sans installation ni carte bancaire. Selon le nombre d'applications choisies, c'est un essai de quinze jours ou une application gratuite sans limite de durée. Les enseignants et les étudiants disposent d'une troisième voie : la base éducative.

~8 minutes de lecture · niveau débutant

Édition : Enterprise. Écrit et vérifié en octobre 2026 sur une base Odoo 20.0 Enterprise hébergée sur odoo.com. Le parcours d'essai a été relevé sur le site d'Odoo le 12 octobre 2026.

Avant de payer un abonnement, ou simplement pour suivre une série d'articles Enterprise sur son propre écran, le plus court chemin est une base hébergée par Odoo. Elle se crée depuis un formulaire en ligne, sans rien installer. Les choix faits à ce moment ont pourtant des conséquences : la durée de l'essai, le plan facturé ensuite, les données présentes dans la base.

Objectifs

À la fin de cet article, vous saurez :

  • créer une base d'essai Odoo 20 Enterprise depuis le site d'Odoo ;
  • prévoir la durée de l'essai selon le nombre d'applications choisies ;
  • demander une base éducative, et à qui elle s'adresse ;
  • vérifier l'édition de la base et y charger, si besoin, les données de démonstration.

1. Ouvrir la page d'essai

Sur le site d'Odoo, le bouton Essai gratuit, en haut à droite, ouvre la page Sélectionnez vos Applications. Elle annonce un « accès gratuit et instantané » et l'absence de carte de crédit. Les applications y sont rangées par domaine : Site Web, Ventes, Finance, Services, Productivité, Chaîne d'approvisionnement, Marketing, Ressources humaines et Personnalisations (Studio).

Cette page s'atteint aussi depuis la page d'accueil d'Odoo, par le même bouton Essai gratuit.

2. Choisir les applications : gratuit ou quinze jours

Cliquez sur une carte pour la sélectionner. Un panneau récapitule le choix et, surtout, en indique la conséquence :

  • avec une seule application, la base est « gratuite, avec des utilisateurs illimités, pour toujours ». C'est le plan Une App Gratuite ;
  • dès la deuxième application, le panneau annonce « 15 jours d'essai gratuit. Aucune carte de crédit requise. »

Une application arrive avec celles dont elle dépend. Sur la page d'essai, Fabrication déclare ainsi Inventaire, Code-barres, Employés et la gestion des compétences : la base les contiendra même si le panneau n'affiche que Fabrication. La page des tarifs le confirme : ces applications requises sont offertes avec l'application gratuite.

Pour suivre une série d'articles qui parcourt plusieurs applications, choisissez directement toutes celles qu'elle utilise : c'est alors un essai de quinze jours. Pour tester un seul outil dans la durée, une application suffit.

3. Remplir le formulaire

Le bouton Continuer mène au formulaire Démarrez maintenant. Il demande le nom et prénom, le nom de l'entreprise, une adresse e-mail et un numéro de téléphone, puis le pays, la langue, la taille de l'entreprise et l'intérêt principal. Le lien Modifier la sélection d'applications ramène à l'étape précédente.

Le pays et l'indicatif téléphonique sont proposés d'après la connexion : vérifiez-les avant de valider. Un clic sur Démarrez maintenant crée la base et vaut acceptation des Conditions d'Abonnement d'Odoo, rappelées juste au-dessus du bouton. La base est ensuite accessible à une adresse en .odoo.com.

4. Pour un cours : la base éducative

Le programme éducatif d'Odoo s'adresse aux enseignants et à leurs étudiants. Il propose notamment de créer des bases Odoo Online pour une classe. La page d'essai a pour cela une variante, odoo.com/trial?edu=1. La sélection des applications est la même, mais le panneau change de message.

La base porte alors un nom qui commence par edu-. Les articles Enterprise d'OdooSkills sont écrits sur une base de ce type, avec les données de démonstration d'Odoo : les mêmes manipulations peuvent donc être refaites sur une base d'essai ordinaire.

5. Premiers pas dans la base

La base s'ouvre sur l'écran d'accueil d'Odoo : une icône par application installée, celles qui ont été choisies et celles qui sont venues avec elles. Celui de la base de démonstration d'OdooSkills regroupe les applications de production (Fabrication, Atelier, Qualité, Maintenance, GCVP) et leurs voisines.

Trois vérifications utiles dès la première connexion :

  1. L'édition. Dans Paramètres, le bloc À propos affiche « Odoo 20.0+e (Edition Enterprise) ».
  2. Les autres applications. Le menu Apps liste les 80 applications d'Odoo 20 Enterprise. Celles qui ne sont pas installées portent le bouton Installer.
  3. Les données de démonstration. Pour retrouver à l'écran les clients, articles et ordres de fabrication des articles, activez le mode développeur (Paramètres, bloc Outils développeur), puis cliquez sur Charger les données de démonstration dans ce même bloc. Le lien n'apparaît que si la base n'en contient pas encore.

Et en Community ?

Pas d'essai en ligne : une installation

La page d'essai crée des bases Enterprise hébergées par Odoo. La Community, elle, s'installe sur un poste ou un serveur, puis la base se crée depuis le gestionnaire de bases de données, avec la case des données de démonstration à cocher. Les deux étapes sont détaillées dans Créer sa base Odoo 20 Community.

Points de vigilance

Les données de démonstration ne s'enlèvent plus

Odoo prévient avant de les charger : elles sont réservées aux bases de test et, une fois chargées, ne peuvent plus être retirées. Ne les chargez jamais dans une base destinée à devenir la base de production de l'entreprise : créez plutôt une seconde base d'essai pour l'apprentissage.

Une deuxième application change le plan

Dans une base créée avec une seule application, installer une autre application depuis le menu Apps fait passer au plan Standard, selon la FAQ des tarifs d'Odoo.

Le formulaire part d'une connexion, pas d'une entreprise

Le pays et l'indicatif sont préremplis d'après la connexion, pas d'après l'entreprise. Depuis l'étranger ou derrière un VPN, ils peuvent être faux : relisez-les avant de cliquer sur Démarrez maintenant.

Exercice

Objectif : préparer une base d'essai pour suivre la série Enterprise sur la production.

Indication : sur la page d'essai, sélectionnez Fabrication, Qualité et Maintenance, puis observez le panneau avant de cliquer sur Continuer.

Critère de réussite : le panneau annonce un essai de 15 jours, et vous savez dire pourquoi la sélection de Fabrication seule aurait donné une base gratuite.

À retenir

  • La page d'essai d'Odoo crée une base Enterprise hébergée, sans carte de crédit.
  • Une application : gratuite pour toujours. Deux ou plus : 15 jours d'essai (relevé le 12 octobre 2026).
  • La variante éducative (trial?edu=1) garde les données jusqu'à 24 mois.
  • Paramètres › À propos confirme l'édition ; les données de démonstration se chargent en mode développeur, de façon irréversible.
