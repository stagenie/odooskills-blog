Qu'est-ce qu'Odoo ?

Odoo (anciennement OpenERP, puis Tiny ERP) est un progiciel open source de gestion intégré. Il propose une suite d'applications interconnectées, partageant une base de données unique, qui couvrent l'ensemble des fonctions de l'entreprise.

Avec plus de 12 millions d'utilisateurs à travers le monde, Odoo est le système ERP open source le plus populaire. Sa modularité lui permet de s'adapter à des entreprises de toutes tailles, son interface 100% web et responsive, et la richesse de ses fonctionnalités en font l'un des ERP les plus déployés au monde.

Odoo se décline en deux éditions : Community (LGPL-3, gratuite) et Enterprise (licence propriétaire, avec des fonctionnalités supplémentaires et le support officiel).

L'histoire d'Odoo

De Tiny ERP à Odoo 19 — plus de 20 ans d'évolution continue.

2005

Tiny ERP — Première version stable, créée par Fabien Pinckaers, un étudiant belge passionné.

2011

OpenERP 6.0 — Lancement du SaaS (version à la demande) et approche modulaire renforcée.

2014

OpenERP devient Odoo — Version 8 : CMS, e-commerce, marketing. L'ERP dépasse ses frontières.

2015

Community + Enterprise — Séparation des éditions. Community sous LGPL-3, Enterprise payant.

2021

Odoo 15 — Introduction du framework OWL (Odoo Web Library), remplacement des widgets legacy.

2023

Odoo 17 — Nouvelle interface, refonte complète des vues list/form, suppression des attrs XML.

2024

Odoo 18 — Nouveaux champs de connaissance, améliorations comptabilité et POS, IA intégrée.

2025

Odoo 19 — Version actuelle. Contraintes SQL simplifiées, Domain(), OWL mature, performance accrue.

Architecture technique

Odoo repose sur une architecture trois tiers classique, optimisée pour le web.

DB

PostgreSQL

Le SGBD relationnel qui stocke toutes les données et configurations. Odoo utilise son propre ORM pour communiquer avec PostgreSQL — pas de requêtes SQL directes dans le code métier. Chaque base = une instance Odoo complète.

PY

Serveur Odoo (Python)

Le coeur du système : logique métier, ORM, moteur de workflow, calculs et rapports. Le serveur expose des API (XML-RPC, JSON-RPC) et sert les pages web. Les modules custom s'écrivent en Python et XML.

JS

Client Web (OWL)

L'interface utilisateur, 100% web, construite avec le framework OWL (Odoo Web Library) — un framework JavaScript réactif développé par Odoo. Il s'exécute dans le navigateur et communique avec le serveur via des appels RPC.

Comment ça fonctionne ?

Le navigateur charge l'application OWL, qui envoie des requêtes au serveur Python. Le serveur exécute la logique métier, interroge PostgreSQL via l'ORM, puis renvoie les données au client. Celui-ci les affiche sous forme de listes, formulaires, kanban, calendriers ou graphiques. Tout est modulaire : chaque module peut ajouter ou étendre des vues, des modèles et de la logique.

Le modèle d'Odoo

Comprendre les deux éditions et le positionnement unique d'Odoo.

Community (gratuit)

Licence LGPL-3. Accès complet au code source. Toutes les applications de base sont incluses : CRM, Ventes, Achats, Inventaire, Comptabilité, Fabrication, Website, etc. Vous pouvez l'installer, le modifier et le redistribuer librement.

Idéal pour : PME, startups, développeurs, apprentissage

Enterprise (payant)

Toutes les fonctionnalités Community + des modules avancés : Studio (personnalisation no-code), Marketing Automation, Qualité, Consolidation comptable, Helpdesk avancé, IoT, etc. Inclut le support officiel et l'hébergement Cloud (Odoo.sh).

Tarif : à partir de ~24,90 EUR/utilisateur/mois

Ce qui rend Odoo unique

  • Suite intégrée, pas un agrégat — toutes les apps partagent la même base, pas d'interfaçage
  • Modularité — commencez avec une app, ajoutez les autres au fil des besoins
  • Conformité locale — plans comptables, taxes et formats légaux adaptés par pays
  • Personnalisation — développez vos propres modules ou étendez les modules existants
  • Communauté massive — 4 500+ partenaires, OCA, et des milliers de modules tiers
  • Coût compétitif — bien inférieur à un SAP, Dynamics ou NetSuite

L'homme derrière Odoo

Fabien Pinckaers lance Tiny ERP en 2005, alors étudiant en Belgique. De petit projet personnel, le logiciel grandit de manière organique avec une croissance moyenne de 60% par an sur les 15 dernières années.

Aujourd'hui, Odoo SA compte plus de 4 000 employés répartis entre la Belgique, l'Inde, les États-Unis et l'Asie. La société génère un chiffre d'affaires dépassant les 500 millions d'euros et continue d'investir massivement dans le recrutement et le développement produit.

"Il y a deux types d'acteurs sur le marché. Les ERP coûteux et pénibles à utiliser, et les apps simples qui ne font qu'une seule chose. Notre challenge est d'avoir un champ fonctionnel complet ET une hypersimplicité d'utilisation."
— Fabien Pinckaers
