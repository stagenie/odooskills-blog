Odoo 20 Community : les 34 applications gratuites

Ventes, CRM, Facturation, Inventaire, Fabrication, Site web, Point de vente, Ressources humaines : l'édition Community d'Odoo 20 couvre la plupart des fonctions d'une entreprise. Cet article dresse la liste complète des 34 applications, montre comment les reconnaître dans votre base et sépare clairement ce qui relève de l'édition Enterprise.

~9 minutes de lecture · niveau débutant · série Fonctionnel Odoo 20

Édition : Community. Écrit et vérifié sur Odoo 20.0 Community, septembre 2026, sur une base créée avec les données de démonstration.

Objectifs

À la fin de cet article, vous saurez :

  • quelles sont les 34 applications de la Community, classées par métier, avec leur nom dans les menus ;
  • distinguer, dans l'écran Applications, une application gratuite d'une application Enterprise ;
  • ce qu'installent avec elles les principales applications ;
  • dans quel ordre découvrir Odoo 20.

Deux éditions, une même base de code

Odoo 20 existe en deux éditions. L'édition Community est publiée sous licence libre LGPL-3 : chacune de ses 34 applications porte cette licence dans son manifeste. Elle s'installe gratuitement, sur un poste ou sur un serveur. L'édition Enterprise comprend en plus des applications sous licence propriétaire Odoo (OEEL-1), dont la base Community renvoie vers la page des tarifs d'Odoo.

Ce qui distingue précisément l'Enterprise, application par application, fera l'objet d'une série dédiée, écrite sur une base Enterprise.

Pour une comparaison générale des deux éditions et du choix d'Odoo, l'article Pourquoi choisir Odoo ? reste la référence. Le présent article s'en tient à ce que contient, concrètement, une base Odoo 20 Community.

Où voir les applications dans votre base

Une base Community neuve ne contient encore aucune application : seulement les réglages et l'écran qui sert à les installer.

  1. Connectez-vous avec un compte administrateur : les boutons d'installation ne s'affichent que pour lui.
  2. Ouvrez le menu Apps. L'écran liste 53 applications : les 34 de la Community, et 19 applications Enterprise présentées au même endroit.
  3. Lisez le bouton de chaque carte. Activer désigne une application Community, installable immédiatement. Mettre à niveau désigne une application Enterprise : elle n'est pas installable dans une base Community, et le bouton ouvre la page des tarifs d'Odoo.

Les descriptions de l'écran Applications sont en anglais

Même dans une base en français, l'écran Applications affiche le nom et la description de chaque application en anglais : « Sales », « Invoicing », « Inventory ». Une fois l'application installée, son menu porte le nom français : Ventes, Facturation, Inventaire. Les tableaux ci-dessous donnent les deux noms.

La description de l'application Website indique « Enterprise website builder ». Il s'agit pourtant d'une application Community : c'est le bouton qui fait foi, pas la description.

Ventes n'installe pas Inventaire

Une entreprise qui vend des produits stockés active aussi Inventaire : Odoo installe alors de lui-même le module qui relie les deux applications (sale_stock).

Par où commencer

Installer les 34 applications d'un coup n'aide pas à comprendre Odoo. La série fonctionnelle Odoo 20 suit un ordre qui part du cœur de l'activité :

  1. Ventes, qui installe aussi Facturation ;
  2. CRM, en amont des ventes ;
  3. Facturation, pour encaisser et suivre les paiements ;
  4. Achats, Inventaire et Fabrication ;
  5. Projet et les services ;
  6. Ressources humaines ;
  7. Site Web, eCommerce et Point de Vente.

Chaque article s'appuie sur les données de démonstration d'Odoo, pour que votre écran ressemble aux captures. À la création de la base, la case Demo Data est décochée par défaut : cochez-la. L'installation d'Odoo 20 sur un poste Ubuntu est détaillée dans Installer Odoo 20 sur Ubuntu ; la création de la base et les premiers réglages feront l'objet du prochain article de la série.

Exercice

Objectif : repérer, dans votre propre base, les applications de chaque édition.

Indication : ouvrez le menu Apps et comparez les boutons des cartes. Activez ensuite l'application Contacts.

Critère de réussite : vous comptez 19 cartes « Mettre à niveau ». Après l'activation, le menu principal affiche Contacts, ainsi que Discussion, installée au passage.

À retenir

  • Odoo 20 Community compte 34 applications, toutes sous licence libre LGPL-3.
  • L'écran Applications en affiche 53 : les 19 autres sont des applications Enterprise, marquées « Mettre à niveau ».
  • Les noms de l'écran Applications sont en anglais ; les menus, eux, sont en français.
  • Une activation installe aussi les applications nécessaires : Ventes apporte Facturation, pas Inventaire.
