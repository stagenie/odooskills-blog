Odoo 20 Studio : ajouter un champ à un formulaire

Une information propre à l'entreprise, une liste de choix sur le devis, une colonne de plus dans la liste : Studio, l'outil de personnalisation de l'édition Enterprise d'Odoo 20, les ajoute sans écrire de code.

~7 minutes de lecture · niveau intermédiaire

Édition : Enterprise. Écrit et vérifié sur Odoo 20.0 Enterprise (base hébergée sur odoo.com), octobre 2026.

L'équipe commerciale veut savoir, d'un coup d'œil, quels devis sont urgents. Odoo n'a pas de champ prévu pour cela : l'information finit dans une note, ou dans un tableur à côté. Le besoin est simple, un champ de plus sur le devis, avec une liste de choix, visible sur la fiche et dans la liste.

Dans l'édition Enterprise d'Odoo 20, ce champ s'ajoute avec Studio. Cet article installe Studio sur une base de démonstration, puis ajoute au devis un champ Niveau d'urgence (Normal, Urgent, Très urgent) : placé dans le formulaire, réglé, affiché dans la liste des devis, puis rempli sur un devis de démonstration. Un seul modèle est modifié, celui des devis ; aucun champ standard n'est renommé ni masqué.

Objectifs

À la fin de cet article, vous saurez :

  • ouvrir Studio sur l'écran à personnaliser ;
  • glisser un nouveau champ dans un formulaire et définir ses valeurs ;
  • régler son libellé et son infobulle d'aide dans les propriétés ;
  • ajouter le même champ, en colonne, dans une vue liste ;
  • retrouver le nom technique du champ et les vues que Studio a modifiées.

Un champ, deux vues

Studio sépare deux choses que l'écran montre ensemble : le champ, qui s'ajoute au modèle (ici, le devis) et garde la valeur saisie, et les vues, qui décident où le champ s'affiche. Le champ est créé une fois ; il se place ensuite dans chaque vue qui doit le montrer.

La case sarcelle est le champ lui-même, avec son nom technique : il existe dès que les valeurs sont validées. Les deux cases qui en partent sont les deux vues modifiées, le formulaire du devis et la liste des devis. Les étapes 2 à 6 suivent ce schéma de haut en bas.

1. Installer Studio

Dans l'écran Applications, Studio porte la description « Create and customize your Odoo apps ». Sur la base de démonstration, son installation a ajouté deux modules liés : web_studio_ai_fields (« Enable creating AI computed fields in studio ») et website_studio (« Display Website Elements in Studio »). Aucune fenêtre ne s'est ouverte pendant l'installation.

Studio n'ajoute pas d'icône dans le menu des applications : il s'ouvre par une nouvelle icône, en forme d'outils croisés, dans la barre du haut, à gauche du nom de la société. Son info-bulle est « Toggle Studio ».

2. Ouvrir Studio sur le formulaire du devis

Studio s'ouvre sur l'écran affiché. Ouvrez un devis dans Ventes (ici le devis de démonstration S00003, client Ready Mat), puis cliquez sur l'icône de Studio. L'écran passe en édition :

  • la barre du haut garde les menus de Ventes et ajoute Modifier le menu, Nouveau modèle et Fermer ;
  • la seconde barre indique Vues > Formulaire, avec Annuler et Refaire, puis les rubriques de Studio : Vues, Rapports, Automatisations, Actions, Webhooks, Sécurité, Pages modèle, Règles de filtres, et à droite les icônes des types de vues ;
  • le panneau de gauche, onglet Ajouter, propose des Composants (Onglets, Colonne), vingt types de Nouveaux champs et, plus bas, les Champs existants.

Dans l'éditeur, les libellés du formulaire s'affichent en anglais : Customer, Payment Terms, Order Lines. À la sortie de Studio, le formulaire retrouve ses libellés français (étape 6).

3. Glisser un champ Sélection et définir ses valeurs

Un champ Sélection propose une liste de valeurs fixée à l'avance. Faites glisser la case Sélection du panneau vers le formulaire et relâchez-la sous Payment Terms, dans le groupe de droite. Studio ouvre aussitôt la fenêtre Propriétés du champ : « Précisez toutes les valeurs possibles ».

Saisissez chaque valeur dans Ajouter une nouvelle valeur, puis validez par Entrée ou par la coche (info-bulle « Add selection »). Trois valeurs ici : Normal, Urgent, Très urgent. Chaque ligne garde une poignée pour changer l'ordre, un crayon pour la modifier et une corbeille pour la retirer.

Mettre à jour crée le champ. Il apparaît dans le formulaire sous le libellé provisoire « Nouveau Sélection », et la barre de Studio affiche Enregistré : Studio enregistre chaque modification au fil de l'eau, sans bouton de sauvegarde.

4. Régler les propriétés du champ

Cliquez sur le champ dans le formulaire : le panneau de gauche passe sur l'onglet Propriétés. Deux réglages ont été faits ici :

  • Libellé : « Niveau d'urgence », à la place de « Nouveau Sélection » ;
  • Infobulle d'aide : « Degré d'urgence de la demande du client. ».

Chaque saisie s'enregistre en quittant la case. Le libellé change aussitôt dans le formulaire, et un point d'interrogation apparaît à sa droite : c'est l'infobulle.

Le panneau montre les autres propriétés disponibles, laissées telles quelles sur la base de démonstration : les cases Invisible, Obligatoire et Readonly (chacune avec un lien Conditionnel), Autofill, Suivre dans le chatter, le Widget, les textes d'exemple (Placeholder), une Valeur par défaut pour la société, le lien Modifier les valeurs (la fenêtre de l'étape 3), et la visibilité par groupes d'utilisateurs. En bas, Supprimer de la vue retire le champ du formulaire.

5. Ajouter le champ à la liste des devis

Le champ est dans le formulaire, pas encore dans la liste. Ouvrez la liste des devis (Ventes, menu Devis), puis l'icône de Studio : la barre indique Vues > Liste. Dans le panneau Ajouter, dépliez Champs existants (« Les champs suivants ne sont actuellement pas dans la vue. ») : le champ Niveau d'urgence y figure. Faites-le glisser dans l'en-tête de la liste, à droite de la colonne Customer.

La colonne apparaît encadrée, vide pour toutes les lignes, et le panneau passe sur ses propriétés. Dans une liste, on y trouve en plus la Largeur de colonne (px). Cliquez sur Fermer, en haut à droite, pour quitter Studio.

6. Saisir une valeur et la retrouver dans la liste

Hors de Studio, le formulaire du devis retrouve ses libellés français, et Niveau d'urgence se place entre Conditions de paiement et Date de livraison. Ouvrez un devis, ici S00002 (Ready Mat) : un clic sur le champ déroule les trois valeurs définies à l'étape 3.

Choisissez Urgent et enregistrez le devis. Au survol du point d'interrogation, l'infobulle réglée à l'étape 4 s'affiche.

Pour personnaliser sa propre base de la même façon, l'essai en ligne de l'édition Enterprise part de la page d'accueil d'Odoo ; Studio s'installe ensuite depuis l'écran Applications.

Dans Ventes, la liste Devis montre la nouvelle colonne Niveau d'urgence entre Client et Total. Après retrait du filtre Mes devis, une recherche sur Ready Mat fait apparaître les quatre documents de ce client : seul S00002 porte une valeur, les autres n'en ont pas encore.

Ce que Studio a créé dans la base

Les manipulations ci-dessus ont laissé trois éléments dans la base de démonstration :

ÉlémentNomRôle
Champ du devisx_studio_selection_1, libellé « Niveau d'urgence »Garde la valeur, avec ses trois choix.
Vue formulaireOdoo Studio: sale.order.form customizationPlace le champ après Conditions de paiement, avec son infobulle.
Vue listeOdoo Studio: sale.order.list.quotation.dashboard customizationAjoute la colonne après Client dans la liste des devis.

Le nom technique vient du type de champ (selection), pas du libellé : le libellé choisi ensuite ne l'a pas changé. Les deux vues de Studio complètent les vues d'origine sans les remplacer : elles portent le nom de la vue qu'elles modifient.

La page Fields and widgets de la documentation d'Odoo 20 précise que le nom technique d'un champ créé par Studio commence par x_studio_, qu'il se voit et se modifie pendant la création si le mode développeur est activé avant d'ajouter le champ, et qu'ensuite il ne se modifie plus que par les réglages techniques de la base, après avoir retiré le champ de toutes les vues. Ce changement de nom n'a pas été essayé sur la base de démonstration.

Et en Community ?

Community

Odoo 20 Community ne contient pas Studio : le module web_studio n'y figure pas, et aucun article Community du blog ne traite ce besoin. Le socle commun sait pourtant gérer des champs ajoutés : un champ dont le nom commence par x_ peut être déclaré depuis Paramètres › Technique › Structure de la base de données › Champs, en mode développeur. Le placer dans un formulaire ou une liste demande alors d'écrire une vue héritée en XML.

L'écriture d'une vue héritée est présentée dans Héritage de vues en Odoo 20, sur le blog Développement. Studio fait le même travail par glisser-déposer : il crée le champ et les vues héritées, comme le montre le tableau ci-dessus.

Points de vigilance

Le nom technique se fixe à la création

Sans mode développeur, Studio a nommé le champ x_studio_selection_1, et le libellé « Niveau d'urgence », choisi après, ne l'a pas renommé. C'est sous ce nom que le champ est enregistré dans la base. Pour choisir un nom parlant, activez le mode développeur avant de glisser le champ, comme l'indique la documentation d'Odoo.

Chaque vue se modifie à part

Le champ ajouté au formulaire n'est pas apparu de lui-même dans la liste : il a fallu ouvrir la vue liste dans Studio et l'y glisser depuis Champs existants. La modification faite ici concerne la liste des devis ouverte depuis Ventes ; vérifiez chaque liste où l'équipe doit voir la colonne.

Studio et le plan tarifaire sur Odoo Online

Selon la page des tarifs d'odoo.com (relevée le 15 octobre 2026), installer Studio sur une base Odoo Online la fait passer automatiquement au plan Personnalisé. Vérifiez le plan de l'abonnement avant d'installer Studio sur une base de production.

Exercice

Objectif : ajouter au devis un champ Case à cocher « Échantillon envoyé » et le montrer dans la liste.

Indication : ouvrez Studio sur un devis, glissez Case à cocher dans le formulaire, réglez le libellé dans Propriétés, puis passez sur la vue liste et glissez le champ depuis Champs existants.

Critère de réussite : après Fermer, la case se coche sur un devis de démonstration, et la liste Devis affiche une colonne « Échantillon envoyé » cochée pour ce devis.

À retenir

  • Studio est propre à l'édition Enterprise ; il s'ouvre par l'icône de la barre du haut, sur l'écran affiché.
  • Un nouveau champ se glisse depuis le panneau Ajouter ; un champ Sélection demande ses valeurs dès le dépôt.
  • Libellé, infobulle et autres propriétés se règlent dans l'onglet Propriétés ; Studio enregistre au fil de l'eau.
  • Le champ appartient au modèle, mais chaque vue se modifie à part : la liste reçoit le champ depuis Champs existants.
  • Studio a créé ici le champ x_studio_selection_1 et deux vues héritées « Odoo Studio: … customization ».
