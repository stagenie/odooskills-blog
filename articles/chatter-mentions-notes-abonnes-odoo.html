Le chatter d'Odoo 20 : notes, mentions et abonnés

Sous chaque devis, facture ou fiche d'Odoo 20, le chatter garde l'historique du document et sert de fil d'échange. Encore faut-il savoir qui lit quoi : un message part chez le client, une note reste en interne, une mention prévient un collègue précis. Voici comment s'en servir sans surprise.

~5 minutes de lecture · niveau débutant · série Astuces Odoo 20

Édition : Community. Écrit et vérifié sur Odoo 20.0 Community, octobre 2026, sur la base de démonstration (application Ventes, devis S00003 du client Ready Mat). Le chatter est fourni par le module Discussion, présent aussi dans l'édition Enterprise ; il fonctionne de la même façon sur les autres documents.

La réponse en bref

  1. Envoyer message écrit au client et aux abonnés du document ; Note reste interne.
  2. Tapez @ suivi d'un nom pour mentionner un collègue : il est prévenu même s'il ne suit pas le document.
  3. Le trombone joint un fichier au message ; il est aussi rangé dans les fichiers du document.
  4. L'icône personne (avec son compteur) gère les abonnés et ce que chacun reçoit.

1. Envoyer message ou Note : qui reçoit quoi

Le chatter se trouve à droite du formulaire sur un écran large (1920 pixels), sous le formulaire sur un écran plus étroit (1280 pixels). Sa barre porte trois boutons, Envoyer message, Note et Activité, puis à droite une loupe (« Rechercher des messages »), un trombone et l'icône des abonnés.

  1. Ouvrez Ventes › Commandes › Devis et cliquez sur un devis.
  2. Cliquez sur Envoyer message. Le champ À se remplit : le client du document y figure déjà, et les abonnés apparaissent sous la forme « 1 Follower ». Le sujet reprend la référence du devis.
  1. Cliquez maintenant sur Note. Le champ À disparaît, la zone de saisie indique « Enregistrer une note interne… » et le bouton devient Publier.

La note ne part pas chez le client. Elle reste visible des utilisateurs internes qui ouvrent le document. Les abonnés ne la reçoivent pas non plus par défaut : seule la mention prévient quelqu'un (section suivante).

2. Mentionner un collègue avec @

  1. En mode Note, tapez @ puis le début d'un nom : Odoo propose les utilisateurs correspondants.
  2. Cliquez sur le nom, écrivez la suite de la note, puis Publier.

Dans une note, Odoo 20 limite les suggestions aux utilisateurs internes : sur la base de démonstration, « @Ready » ne propose rien en mode Note, alors que le même début de nom propose le client Ready Mat en mode Envoyer message. Une note ne peut donc pas prévenir un client par mégarde.

Le collègue mentionné est prévenu selon son réglage Notifications, dans ses préférences d'utilisateur : Par e-mails ou Dans Odoo. Réglé sur Dans Odoo, il trouve la note dans Discussion › Notifications, avec la référence du document (ici S00003) et le texte. La mention ne l'abonne pas au document : les échanges suivants ne lui parviendront que s'il est de nouveau mentionné ou s'il devient abonné.

3. Joindre un fichier

Sous la zone de saisie, le trombone ajoute un fichier au message ou à la note en cours. Un aperçu s'affiche avant la publication, puis le fichier reste attaché au message dans l'historique.

Le fichier est aussi rangé sur le document lui-même. Le trombone de la barre du chatter porte alors un compteur ; un clic ouvre le panneau Fichiers, qui liste toutes les pièces du devis et propose Joindre des fichiers pour en ajouter sans écrire de message. C'est l'endroit où retrouver un document reçu ou envoyé des semaines plus tôt.

4. Gérer les abonnés

L'icône personne, en haut à droite du chatter, affiche le nombre d'abonnés. Un clic ouvre la liste :

  • Suivre ou Désabonner pour soi-même ;
  • Ajouter des abonnés ouvre la fenêtre « Ajouter des suiveurs à ce document » : choisissez les contacts dans Abonnés, puis Ajouter des abonnés. L'interrupteur Notifier les destinataires est désactivé par défaut : laissé ainsi, aucun courriel d'invitation ne part ;
  • pour chaque abonné, la croix le retire et le crayon règle ce qu'il reçoit.

Chaque case est un type d'événement. Sur la base de démonstration, un nouvel abonné d'un devis reçoit Messages et Devis consulté ; la case Notes est décochée, ce qui explique qu'une note ne prévienne personne sans mention. Mettre à jour applique le choix à ce document ; Update All demande confirmation puis l'applique à tous les documents existants de l'équipe commerciale indiquée sous les cases.

Point de vigilance : vérifier le mode avant d'écrire

Les boutons Envoyer message et Note se ressemblent, et le client est déjà inscrit dans le champ À du premier. Un commentaire interne écrit en mode Envoyer message est donc adressé au client et aux abonnés. Avant de valider, regardez le bouton : Envoyer signifie un message vers l'extérieur, Publier une note interne.

À retenir

  • Envoyer message écrit au client et aux abonnés ; Note reste interne.
  • Dans une note, @ ne propose que des utilisateurs internes et prévient la personne citée, sans l'abonner.
  • Un fichier joint à un message est aussi rangé dans le panneau Fichiers du document.
  • Le crayon d'un abonné règle ce qu'il reçoit ; Notes est décoché par défaut.
