Modèle d'email dans Odoo 20 : créer, réutiliser, gérer

Une relance de devis, une demande de pièce manquante, un accusé de réception : certains courriels s'écrivent chaque semaine presque à l'identique. Odoo 20 permet de les enregistrer comme modèles directement depuis la fenêtre de rédaction du chatter, puis de les rappeler en un clic, avec le nom du client et la référence du document remplis tout seuls.

~5 minutes de lecture · niveau débutant · série Astuces Odoo 20

Édition : Community. Écrit et vérifié sur Odoo 20.0 Community, octobre 2026, sur la base de démonstration avec l'application Ventes, connecté en administrateur. Les modèles de courriel font partie de la messagerie de base et existent aussi dans l'édition Enterprise. Aucun courriel n'a été réellement envoyé pour cet article.

La réponse en bref

  1. Dans le chatter, Envoyer message, puis l'icône Ouvrir l'éditeur complet : la fenêtre « Rédiger un e-mail » s'ouvre.
  2. Rédigez le message, puis bouton ⋮ en bas › Enregistrer comme modèle, donnez-lui un nom.
  3. Pour le réutiliser : même bouton ⋮, cliquez sur le nom du modèle.
  4. Pour ajouter le nom du client ou la référence du document : ⋮ › Gérer les modèles, puis /champ dans le corps et # dans le sujet. Aucun mode développeur n'est nécessaire.

1. Enregistrer un message comme modèle

Un modèle de courriel est attaché à un type de document : créé depuis un devis, il n'est proposé que sur les devis et commandes. L'exemple suit une relance de devis sur la commande S00001 de la démonstration (client Acme Corporation).

  1. Ouvrez le devis (Ventes › Commandes › Devis), puis cliquez sur Envoyer message au-dessus du chatter.
  2. La zone de saisie rapide ne propose pas les modèles. Cliquez sur l'icône Ouvrir l'éditeur complet (les deux flèches en bas à droite de la zone) : la fenêtre Rédiger un e-mail s'ouvre, avec le client dans le champ Vers.
  3. Saisissez le Sujet et le texte du message.
  4. Cliquez sur le bouton ⋮ du pied de fenêtre, à droite de l'horloge de planification.

Sur un devis, la liste Sélectionnez un modèle contient déjà les modèles livrés par Ventes et eCommerce ; les deux commandes utiles ici viennent en dessous.

  1. Choisissez Enregistrer comme modèle. Une petite fenêtre Créer un modèle d'e-mail demande le Nom du modèle.
  1. Cliquez sur Enregistrer le modèle. La fenêtre de rédaction revient, intacte : vous pouvez envoyer le message ou cliquer sur Ignorer.

Le modèle reprend le corps du message tel qu'il est écrit, signature comprise, ainsi que les pièces jointes éventuelles. Il appartient à l'utilisateur qui l'a créé : il apparaît désormais en tête de la liste du menu ⋮.

2. Ajouter le nom du client et la référence du devis

Un modèle qui commence par « Bonjour Acme Corporation » ne sert qu'une fois. Pour qu'il s'adapte à chaque document, il faut y placer des champs dynamiques. Dans la fenêtre de rédaction d'un seul document, le menu « / » ne propose pas d'insérer un champ : l'opération se fait sur la fiche du modèle, accessible sans mode développeur.

  1. Dans la fenêtre de rédaction, ⋮ › Gérer les modèles. La liste Modèles d'e-mail s'ouvre, filtrée sur « Mes modèles » et sur le type de document du devis.
  2. Ouvrez « Relance de devis ». Sous le corps, Odoo rappelle : « Astuce : écrivez /champ pour insérer du contenu dynamique ! ».
  3. Placez le curseur après « Bonjour », tapez /champ et validez Champ. Une bulle s'ouvre : cliquez dans Champ, cherchez « Client », cliquez sur Client, puis sur Mettre à jour. Le corps affiche alors une étiquette « Client ».
  4. Dans le Sujet, tapez « Votre devis » puis le caractère # : la liste des champs s'ouvre. Choisissez Référence commande, puis Insérer, et complétez par « en attente ».
  5. Enregistrez la fiche.

Le sujet montre l'expression brute {{object.name}} : c'est normal, elle désigne la référence du document et sera remplacée à l'utilisation. La case Par défaut de la bulle prévoit un texte de secours si le champ est vide.

3. Réutiliser le modèle sur un autre devis

Sur le devis S00002 (client Ready Mat), le chemin est le même : Envoyer message, Ouvrir l'éditeur complet, ⋮, puis un clic sur « Relance de devis ». Le sujet et le corps sont remplacés par ceux du modèle, avec les valeurs du document ouvert :

Le texte reste modifiable avant l'envoi. La signature n'est pas répétée, et le destinataire proposé est le client du devis.

4. Retrouver, modifier ou supprimer ses modèles

  • Depuis un document : ⋮ › Gérer les modèles ouvre directement vos modèles pour ce type de document.
  • Depuis les paramètres : Paramètres, bloc Modèles d'e-mail, lien Revoir tous les modèles. La liste s'ouvre sur le filtre « Modèles de base » (ceux livrés par les applications) ; retirez-le et choisissez « Mes modèles » ou « Modèles personnalisés ».
  • Modifier : ouvrez la fiche, corrigez le sujet ou le corps, enregistrez.
  • Supprimer : cochez le modèle dans la liste, puis Actions › Supprimer et confirmez (« Au revoir, l'enregistrement ! »). Le même menu propose Archiver pour le retirer sans l'effacer.

Pour partager un modèle avec les collègues, videz le champ Propriétaire dans l'onglet Options : le menu ⋮ affiche les modèles de l'utilisateur et ceux qui n'ont pas de propriétaire. Enfin, la case Restreindre le rendu du modèle des Paramètres, cochée par défaut, encadre la modification des modèles et l'usage des champs dynamiques ; l'administrateur et le groupe « Éditeur de modèle d'e-mail » n'y sont pas soumis.

Point de vigilance : le sujet n'est pas enregistré avec le modèle

« Enregistrer comme modèle » conserve le nom, le corps et les pièces jointes, mais pas le sujet saisi dans la fenêtre : sur la base de démonstration, la fiche du modèle s'ouvre avec un Sujet vide. Sans correction, le modèle appliqué sur le devis S00002 propose pour sujet la seule référence « S00002 ». Passez donc par Gérer les modèles juste après la création pour renseigner le sujet.

À retenir

  • Les modèles se trouvent dans l'éditeur complet du chatter, derrière le bouton ⋮, pas dans la zone de saisie rapide.
  • Un modèle vaut pour un type de document : celui d'un devis n'apparaît pas sur un contact.
  • Les champs dynamiques s'ajoutent sur la fiche du modèle : /champ dans le corps, # dans le sujet, sans mode développeur.
  • Après « Enregistrer comme modèle », complétez le sujet dans Gérer les modèles.
