Mode développeur dans Odoo 20 : l'activer et 5 usages

Le mode développeur n'est pas réservé aux développeurs. Pour un utilisateur d'Odoo 20, il ouvre un menu supplémentaire sur chaque fiche et le menu Technique des Paramètres : savoir qui a modifié une fiche, préremplir un champ, vérifier qu'un e-mail est parti. Le tout sans écrire une ligne de code.

~5 minutes de lecture · niveau débutant · série Astuces Odoo 20

Édition : Community. Écrit et vérifié sur Odoo 20.0 Community, octobre 2026, sur la base de démonstration, société My Company (San Francisco), avec l'administrateur Mitchell Admin. Le mode développeur existe aussi dans l'édition Enterprise.

La réponse en bref

  1. Ouvrez Paramètres, descendez jusqu'à Outils développeur et cliquez sur Activer le mode développeur.
  2. Ou ajoutez ?debug=1 à la fin de l'adresse : https://votre-odoo/odoo/contacts?debug=1.
  3. Une icône d'insecte apparaît dans la barre du haut : son menu agit sur la fiche ouverte, et le menu Paramètres › Technique devient visible.
  4. Pour en sortir : icône d'insecte › Quitter le mode débogage.

1. Activer le mode développeur : trois chemins

Depuis les Paramètres. Ouvrez Paramètres › Paramètres généraux et descendez jusqu'à la section Outils développeur, juste avant « À propos ».

Le premier lien recharge la page avec ?debug=1 dans l'adresse. Les deux autres (« avec les assets », « avec les assets test ») servent aux développeurs qui dépannent l'interface ; un utilisateur n'en a pas besoin. Une fois le mode actif, la même section propose Désactiver le mode développeur.

Depuis l'adresse (l'« URL debug »). Ajoutez ?debug=1 après le chemin de la page, par exemple /odoo/contacts/14?debug=1. Le paramètre reste ensuite dans l'adresse quand vous naviguez dans les menus et quand vous rechargez la page. Ce chemin fonctionne pour tout utilisateur interne : sur la base de démonstration, l'utilisateur Marc Demo, qui n'est pas administrateur, obtient l'icône et son menu de la même façon.

Depuis la palette de commandes. Appuyez sur Ctrl+K, tapez debug et choisissez Activer le mode debug (debug).

2. Cinq usages sans coder

Sur une fiche ouverte, l'icône d'insecte de la barre du haut déroule un menu dont la première section, Enregistrement, concerne la fiche affichée.

Usage 1 — Savoir qui a créé ou modifié une fiche

Icône d'insecte › Métadonnées. La fenêtre affiche l'ID de la fiche, son créateur, la date de création, l'auteur et la date de la dernière modification. Sur la fiche LightsUp, Odoo répond : ID 14, créée et modifiée par OdooBot, l'utilisateur qui charge les données de démonstration. C'est la réponse la plus rapide à la question « qui a touché à cette fiche ? » quand le fil de discussion ne la donne pas.

Usage 2 — Préremplir un champ sur chaque nouvelle fiche

Le cas typique : une société dont presque tous les contacts sont en France.

  1. Ouvrez Contacts, cliquez sur Nouveau et choisissez France dans le champ Pays.
  2. Icône d'insecte › Définir des valeurs par défaut.
  3. Dans Par défaut, choisissez Pays = France, cochez Tous les utilisateurs, puis cliquez sur Enregistrer comme valeur par défaut.

Le contact suivant s'ouvre avec France déjà renseigné, pour l'administrateur comme pour les autres utilisateurs. La liste Par défaut ne propose que les champs remplis et modifiables de la fiche affichée : les étiquettes, par exemple, n'y figurent pas. Les valeurs enregistrées se retrouvent, et se suppriment, dans Paramètres › Technique › Actions › Valeurs par défaut de l'utilisateur.

Usage 3 — Vérifier qu'un e-mail est bien parti

Ouvrez Paramètres › Technique › E-mail › E-mails. Chaque e-mail envoyé par Odoo y figure avec son statut : Sortant (en file d'attente), Envoyé, Reçu, Échec de l'envoi ou Annulé.

Ouvrez un e-mail en échec : l'onglet Motif de l'échec donne la cause (ici « Connexion refusée », faute de serveur sortant). Une fois la cause corrigée, Réessayer remet l'e-mail au statut Sortant, et la file d'envoi le reprend.

Usage 4 — Voir tous les droits d'un utilisateur

Ouvrez Paramètres › Utilisateurs & Sociétés › Utilisateurs et une fiche. En mode développeur, l'onglet Droits d'accès gagne une section Droits supplémentaires (« Multi-sociétés », « Gérer plusieurs entrepôts »…) et la fiche affiche deux boutons, Groupes et Droits d'accès, qui listent tout ce que l'utilisateur peut faire. Le menu Utilisateurs & Sociétés › Groupes apparaît aussi. Utile pour comprendre pourquoi un collègue ne voit pas un menu.

Usage 5 — Gérer les favoris de tous les utilisateurs

Un favori enregistré dans la recherche reste privé à son auteur. L'administrateur les voit tous dans Paramètres › Technique › Interface utilisateur › Filtres définis par l'utilisateur. Sur la base de démonstration, un favori privé créé par Marc Demo y apparaît. Sa fiche permet de le renommer, de le partager (champ Partagé avec : vide, le favori vaut pour tous les utilisateurs) ou, par le menu Actions, de l'archiver ou de le supprimer.

Point de vigilance : une valeur par défaut s'applique à toute la société

Avec « Tous les utilisateurs », la valeur vaut pour chaque nouvelle fiche de la société active, et elle reste en place tant qu'elle n'est pas supprimée dans Valeurs par défaut de l'utilisateur. Seul un administrateur peut la poser : pour un autre utilisateur, ce choix déclenche une « Erreur d'accès » ; il ne peut enregistrer qu'une valeur pour lui-même (« Seulement vous »).

À retenir

  • ?debug=1 dans l'adresse active le mode développeur, pour tout utilisateur interne.
  • L'icône d'insecte agit sur la fiche ouverte : Métadonnées et Définir des valeurs par défaut sont les plus utiles.
  • Paramètres › Technique donne la file des e-mails et les favoris de tous.
  • Pour en sortir : icône d'insecte › Quitter le mode débogage.
